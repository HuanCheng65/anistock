# QQ 机器人：需求说明（v1.0）

安易公开注册前，QQ 机器人需要先做好三件事：**身份验证**（绑定 QQ）、**解除绑定**、**找回密码**。查询资产、行情推送等功能以后再加，接口已经有了（§6）。

账号相关的设计见 `docs/v2-account.md`，接口细节见 `docs/api-v1.md` §3。文案按 `docs/copywriting.md`。

## 1. 为什么这三件事要放在机器人里

安易不收集手机号、邮箱和真实姓名。能证明"这个账号是谁的"的只有一样东西：账号绑定的 QQ。

- **身份验证**：绑定 QQ 就算完成身份验证（`backend/src/kyc.rs`）。完成后才能领取财政补贴、认购新股、进入排行榜。一个 QQ 只能绑一个账号，用来防小号。
- **找回密码**：服务器只把找回密码的验证码发给账号绑定的那个 QQ。

所以，**拿到别人的绑定码，或者冒用别人的 QQ 身份，就能夺走他的账号**。§2 的安全要求是硬性要求。

## 2. 安全要求

1. **绑定、解绑、找回密码只在私聊（单聊）里处理。** 在群里收到这些指令，不调用服务器，只回复"这条指令只在私聊中使用"。原因：群里发出的绑定码，任何人都能抢先兑换，把自己的 QQ 绑到别人的账号上，再用找回密码夺走账号。
2. **`external_id` 一律用私聊事件里发送者的 openid**（单聊消息里的用户 openid）。不用群成员 openid，也不用 QQ 号。
   - ⚠️ 需要确认：官方机器人里，同一个人在私聊和群里的 openid 可能不同。如果不同，群里的查询类指令（§6）就没法对应到账号，只能放在私聊里做，或者使用平台提供的跨场景 ID。请按开放平台的实际行为确认后告诉服务器端。
3. 验证码和绑定码**不写入日志**，也不在群里回显。
4. 机器人令牌只放在机器人的配置里，不进代码仓库。

## 3. 连接服务器

| 项目 | 值 |
|---|---|
| 地址 | 安易网站的同一个域名，路径以 `/api/v1` 开头 |
| 认证 | 请求头 `Authorization: Bearer <令牌>`。令牌由运营者在服务器的 `.env` 里配置：`ANISTOCK_BOT_TOKENS=qqbot:<随机长字符串>` |
| 请求体 | JSON，`Content-Type: application/json` |
| 错误 | 非 2xx 时返回 `{"code": "...", "message": "...", "details": {...}}`。按 `code` 判断情况；`message` 是写给玩家的中文，可以直接转述 |
| 限流 | 机器人令牌每秒 30 次。另外，同一个 QQ 的绑定和找回密码各自每小时最多 5 次，超过时返回 429 `rate_limited` |

## 4. 指令

### 4.1 `/绑定 <绑定码>`（私聊）

玩家先在网页"设置 → 身份验证"里生成绑定码（8 位，10 分钟有效），再私聊机器人发送这条指令。

```
POST /api/v1/bot/bindings
{"code": "K7Q39MZD", "platform": "qq", "external_id": "<发送者 openid>"}
```

| 结果 | 回复 |
|---|---|
| 201 | 已绑定 {account.username}，身份验证已完成。可以领取财政补贴、认购新股、进入排行榜，也可以通过机器人找回密码。 |
| 没有附带绑定码 | 发送“/绑定 绑定码”。绑定码在网页“设置 → 身份验证”中生成。 |
| 422 `bind_code_invalid` | 绑定码不正确或已过期。在网页“设置 → 身份验证”中重新生成。 |
| 409 `already_bound`，`details.side = "qq"` | 这个 QQ 已经绑定了另一个账号。先发送“/解绑”，再绑定。 |
| 409 `already_bound`，`details.side = "account"` | 这个账号已经绑定了其他 QQ。在网页上解除绑定后再试。 |
| 429 `rate_limited` | 尝试次数过多，1 小时后再试。 |

绑定码兑换时不区分大小写，连字符可有可无，直接把玩家发来的内容原样传给服务器即可。

### 4.2 `/解绑`（私聊）

```
DELETE /api/v1/bot/bindings/qq/<发送者 openid>
```

| 结果 | 回复 |
|---|---|
| 204 | 已解除绑定，身份验证随之取消。 |
| 404 `binding_not_found` | 这个 QQ 没有绑定账号。 |

### 4.3 `/找回密码`（私聊）

```
POST /api/v1/bot/password-resets
{"platform": "qq", "external_id": "<发送者 openid>"}
```

201：
```json
{"code": "K7Q3-9MZD", "expires_at": "2026-11-06T21:40:00+08:00", "account": {"id": 4, "username": "alice"}}
```

| 结果 | 回复 |
|---|---|
| 201 | 账号 {account.username} 的验证码：{code}，10 分钟内有效。在登录页选择“忘记密码”，输入用户名、验证码和新密码。验证码只用于本人找回密码。 |
| 403 `not_bound` | 这个 QQ 没有绑定账号，无法通过机器人找回密码。发邮件到 aniex@huanchengfly.top 联系运营者。 |
| 429 `rate_limited` | 尝试次数过多，1 小时后再试。 |

- 新的验证码会让旧的失效。验证码只能用一次；输错 5 次后作废。
- 重设密码后，这个账号在其他设备上的登录全部失效。

### 4.4 `/帮助`

私聊和群里都可以用，不调用服务器：

```
安易机器人
/绑定 绑定码：绑定 QQ，完成身份验证
/解绑：解除绑定
/找回密码：获取重设密码的验证码
以上指令只在私聊中使用。
```

### 4.5 在群里收到 4.1–4.3 的指令

不调用服务器，回复：这条指令只在私聊中使用。

## 5. 验收

在本地起一个服务器（`ANISTOCK_BOT_TOKENS=qqbot:test-token`，`ANISTOCK_REGISTRATION=open`），逐条确认：

1. 网页生成绑定码，私聊 `/绑定 码`：网页"设置 → 身份验证"显示"已通过 QQ 完成"，"我的"里身份验证显示"已完成"。
2. 同一个码再发一次：提示绑定码不正确或已过期。
3. 在群里发 `/绑定 码`：只提示私聊使用，网页上仍然没有绑定。
4. 私聊 `/找回密码`：收到验证码；在登录页"忘记密码"里重设密码，可以用新密码登录，之前登录的设备被登出。
5. 私聊 `/解绑`：网页上身份验证变为"未完成"；再发 `/找回密码`，提示没有绑定账号。
6. 1 小时内连续发 6 次 `/找回密码`：第 6 次提示尝试次数过多。

## 6. 以后的功能（接口已就绪）

机器人可以代表已绑定的玩家读取数据：请求头加 `X-Act-As: qq:<openid>`，权限是 `read:account`（只读）。可以用的接口有 `/me`、`/me/portfolio`、`/me/orders`、`/leaderboard`、行情和资讯类接口，以及 WebSocket 推送（`docs/api-v1.md` §3.3、§5.6）。交易权限还没有开放。
