# 融资融券

第二阶段第 3 项（`docs/roadmap.md`）。让玩家可以借钱买入（融资）、借股票卖出（融券）。有了卖空，泡沫才有对手盘，情绪层第二批（追涨泡沫）依赖它。

规则以 A 股融资融券为蓝本，必要时参考港股、美股，简化处标 ⚠️。表格的第三列写服务哪条原则（`docs/game-design.md` 开头的三条：1 尽量真实，2 易上手有深度，3 好玩）。参数都在 `server/game.toml` 的 `[margin]` 段，下文写的是默认值。

---

## 1. 经济需要

| 需要 | 说明 |
|---|---|
| 融资 | 看好一支股票、现金不够时可以加杠杆，代价是利息和被强制平仓的风险 |
| 汇总信息 | 只能做多时，觉得贵的人只能不买，悲观看法进不了价格。能卖空后，高估的股票有人卖，价格更快回到合理水平（Miller 1977；Diamond & Verrecchia 1987） |
| 对手盘 | 情绪层第二批的追涨泡沫，需要有人能做空才会破裂 |

## 2. 账户

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 开通信用账户的条件：注册满 7 天，净资产不低于初始资金的 50%（50,000 币）；穿仓后要先重整才能再开 | A 股：证券账户开户满 6 个月、前 20 个交易日日均资产不低于 50 万元。⚠️ 按游戏时间压缩；资产取当前值，不取 20 日均值 | 1、2：先玩一周熟悉规则再加杠杆 |
| 开通后，**原账户就是信用账户**：现金和全部持仓都是担保物，不分普通账户和信用账户，不需要划转 | 美股的保证金账户（margin account）就是这样；A 股要分开两个账户并划转担保物。⚠️ 简化：一个账户更容易理解 | 2 |
| 游戏里没有资金转出，所以没有“维持担保比例 300% 以上才能提取”这条 | A 股：维持担保比例超过 300% 才能提取超出部分 | — |
| **净资产 = 现金 + 持仓市值 − 负债**。负债 = 融资欠款（本金 + 未付利息）+ 融券欠券按最新价的市值 + 未付融券费用 + 穿仓欠款。排行榜、资产曲线、重整门槛都用净资产；没有开通信用账户的玩家，净资产就是原来的总资产 | 会计恒等式；A 股软件里“总资产”是毛资产，“净资产”扣除负债 | 1、3：利息和费用都是成本，排行榜上不能靠借来的钱排名 |

## 3. 标的证券与担保物

| 规则 | 现实依据 | 原则 |
|---|---|---|
| **标的证券**（可以融资买入、融券卖出的股票）：上市满 5 个交易日，昨收不低于 1 币，没有面值退市倒计时，也没有收入偏低的退市倒计时 | A 股：上市满 20 个交易日（注册制首日即可），ST、*ST、退市整理期股票不能作为标的。⚠️ 天数按游戏时间压缩 | 1 |
| **折算率**：现金 100%；标的证券 70%；其他股票 0%（不能充当保证金，但仍计入维持担保比例） | A 股：现金 100%，股票最高 70%，ST 股 0% | 1 |
| 单支股票的融资余额不超过它的流通市值的 25%，融券余量不超过流通股数的 25%；到达上限后暂停该股的融资买入或融券卖出，了结不受影响。流通股 = 总股数 − 制作委员会持股 − 公司自己持有的未售新股 | 沪深交易所：单只标的融资余额、融券余量达到流通市值或流通股本的 25% 时暂停 | 1：防止用杠杆在小盘股里拉抬或砸盘 |
| **集中度**：单支股票的融资余额加融券市值不超过净资产 | 券商对单一证券集中度的限制（单一证券占担保物比例过高时提高保证金要求或限制新增）。⚠️ 简化为一个比例 | 1：杠杆不能全部压在一支股票上 |

## 4. 融资

| 规则 | 现实依据 | 原则 |
|---|---|---|
| **融资保证金比例 100%**：新增 X 币融资，需要 X 币可用保证金 | A 股现行 100%（2023 年 9 月曾降到 80%）；美股 Reg T 初始保证金 50%，即同样最多 2 倍 | 1 |
| **可用保证金** = 现金 + Σ 持仓市值 × 折算率 − 负债 − 保证金比例 ×（融资欠款 + 融券市值）。新的融资买入、融券卖出在成交后的估算值不能为负；挂着没成交的信用委托按已成交计算 | A 股“保证金可用余额”的公式还要分别计算融资、融券的浮盈浮亏并乘折算率。⚠️ 简化为同一个式子，效果相近：全现金账户最多融资约 1/(2 − 折算率) 倍，即 0.77 倍 | 1、2 |
| **融资利率 = 政策利率 + 3%**（年化），按日计息 | A 股券商融资利率约 5%–8.35%，多数随贷款市场报价利率浮动加点；美股按基准利率加点 | 1：央行加息，杠杆成本跟着上升 |
| 利息每天日结时计提，从可用资金中扣付；可用资金不够时计入负债，以后有钱时先付利息 | A 股按日计息、按月或还款时结息。⚠️ 简化：每天结一次，玩家能马上看到成本 | 2 |
| 融资借来的钱只能买股票，委托下单时借出、冻结在委托里，没有成交的部分撤单时自动还回 | A 股：融资资金直接用于买入，不进入客户可用资金 | 1 |
| 融资不能用于新股认购 | A 股规定融资资金不能用于申购新股 | 1 |
| 还款方式：**卖券还款**（卖出持仓，所得先还本股票的融资欠款，再还其他欠款；先还利息再还本金），**直接还款**（用现金） | A 股的卖券还款、直接还款 | 1 |
| 融资会创造货币：借款从 world 账户付出，进入玩家现金再流向卖方，所以计入货币供应量，央行按货币增速加息时会把这部分算进去 | 现实中银行和券商的信贷扩张就是货币创造 | 1 |
| 合约**没有固定期限**，只要维持担保比例够、按时付利息就可以一直持有 | A 股合约期限最长 6 个月，可以展期；美股、港股保证金贷款没有期限。⚠️ 一季只有 13 周，6 个月期限几乎碰不到，展期又要多一套操作 | 2 |

## 5. 融券

| 规则 | 现实依据 | 原则 |
|---|---|---|
| **券源是制作委员会的持股**：委员会最多借出持股（含已借出部分）的 50%；可借数量 = 50% ×（委员会持股 + 已借出）− 已借出。借出的股票确实转到借券人手里，卖给买方后，买方得到完整的股东权利 | 转融通和证券出借：长期持股的机构（社保、公募、大股东）把股票借给券商再融出，收取出借费。A 股战略投资者配售股可以出借 | 1：卖空必须有真实的股票，股数守恒 |
| **融券保证金比例 100%** | A 股 2023 年 10 月起从 50% 提高到 80%，2024 年起 100% | 1 |
| **融券费率 = 政策利率 + 5%**（年化），按欠券的最新市值每天计提，日结时扣付，付给出借人 | A 股融券费率约 8%–10.6%，比融资利率高约 2 个百分点 | 1 |
| 出借人是制作委员会，它的收入流出游戏经济（和它拿到的分红一样），所以融券费用、分红补偿都付给 world 账户 | 与现有规则一致：委员会的分红是“利润汇回海外” | 1 |
| **融券卖出价格不能低于最新成交价**，只能用限价委托 | A 股：融券卖出的申报价格不得低于该证券的最新成交价；美国 SEC Rule 201 在大跌时也有类似限制 | 1：卖空只能挂在上面等人买，不能连续砸低价格 |
| 融券卖出所得冻结，只能用于买券还券；还清后剩余部分解冻 | A 股：融券卖出所得资金只能用于买券还券（以及少数规定用途） | 1：防止用卖空所得再去加杠杆 |
| 冻结的卖出所得照常计存款利息 | ⚠️ A 股多数券商不付利息。存款利率（政策利率 − 1%）低于融券费率，卖空仍要付净成本 6% 以上，不构成套利 | 2：少一条特殊规则 |
| **分红补偿**：欠券期间遇到分红，借券人按欠券数量 × 每股分红补给出借人 | 证券借贷的“制造股息”（manufactured dividend）：真实股东拿到公司分红，出借人由借券人补偿 | 1：在分红前卖空不能白拿分红 |
| 还券方式：**买券还券**（用冻结的卖出所得和可用资金买入，股票直接还给出借人）。不设直接还券 | A 股有直接还券（用持有的同一股票还）。⚠️ 这里不允许同一支股票同时持有多头和空头，所以没有可用于直接还券的持仓 | 2 |
| 同一支股票不能同时做多和做空：持有它时不能融券卖出；欠它的券时，普通买入和融资买入都改用买券还券 | A 股：融券卖出前持有该证券的需先卖出，未了结融券时不能普通买入同一证券 | 1、2：避免锁仓带来的税费和计算问题 |
| 不设出借人提前召回 | 现实中出借人可以召回，借券人被迫平仓。⚠️ 委员会是 NPC，召回只会带来随机的强制平仓，不增加深度 | 2 |

## 6. 维持担保比例与强制平仓

**维持担保比例 =（现金 + 持仓市值）÷ 负债**，按最新价计算，持仓不打折。没有负债时不显示。

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 维持担保比例**低于 130%** 时，日结发出追加担保物通知（追保）。到下一次日结时仍低于 130%，转入强制平仓 | A 股：低于 130% 时券商通知追保，客户在约定期限内（通常 T+2）补足，否则强制平仓。⚠️ 期限按游戏时间压缩为 1 天 | 1 |
| 盘中维持担保比例**低于 110%**，或净资产为负时，立即强制平仓 | 券商合同中常见的“盘中平仓线”（110%–120%），用来在大跌时减少穿仓 | 1：没有涨跌停，价格可以一天跌很多 |
| 追保期间和强制平仓期间不能新增融资融券，只能还款还券 | 券商在追保期间限制新增负债 | 1 |
| **强制平仓只在连续交易时段进行**，每分钟一轮：先撤销该账户的全部委托，用可用资金付清利息费用、还融资本金；再用冻结的卖出所得和可用资金买券还券；还不够时，按市值从大到小卖出持仓还款。直到维持担保比例回到 150% 以上，或负债清零 | A 股券商在交易时段内按合同约定的顺序平仓，平到约定比例或全部了结 | 1 |
| 平仓委托用**带保护的限价**：卖出价不低于最新价的 95%，买入价不高于最新价的 105%（再受冷静期区间限制），没成交的部分立即撤销，下一分钟按新价格再来 | 券商的平仓指令一般用限价或带保护价的市价，避免在流动性差时一次砸穿 | 1：强平不能把价格砸到不合理的位置 |
| **穿仓**：持仓卖完以后净资产仍为负，剩余的融券按最新价折成现金了结，账户里剩余的现金全部用于偿还，还不清的部分记为穿仓欠款，信用账户关闭 | 现实中客户欠券商的钱，券商追偿；A 股出现过 2015 年的大面积穿仓 | 1 |
| 穿仓欠款由破产重整承担：穿仓后可以随时申请重整，不受每季一次的限制。重整时 world 账户核销欠款，再把现金补到初始资金 | ⚠️ 现实中债务不会因此消失。游戏里没有法院和追偿，由 world 账户（相当于券商的坏账）承担 | 3：亏光的人能继续玩 |
| 穿仓的代价体现在排行榜：重整时本段收益按“净资产 ÷ 本段期初”连乘，净资产为负时记为 0，即此后累计收益率永远是 −100% | 时间加权收益率的连乘规则；基金净值归零就是 −100% | 3：加杠杆赌一把、输了重来，在排行榜上没有好处 |
| 有融资融券负债（不含穿仓欠款）时不能申请重整，要先了结 | 重整按最新价把持仓转给 world 账户，有负债时要先算清 | 1 |

## 7. 与现有规则的关系

| 场景 | 处理 |
|---|---|
| 集合竞价 | 信用委托只在连续交易时段接受。⚠️ A 股集合竞价也能提交信用委托，但融券卖出的价格规则要参照最新成交价，竞价时段的最新价是昨天的 |
| 冷静期 | 照常适用；强平的保护价同时受冷静期区间限制 |
| 04:00 换日 | 信用委托和普通委托一样当日有效 |
| 06:30 日结 | 开头撤销所有信用委托（借出未卖的股票还给委员会，未用的融资还回），避免这些股票领到分红、这些借款领到存款利息；分红、退市之后计息、扣费、计算分红补偿、检查维持担保比例 |
| 分红与除息 | 借来卖掉的股票在买方手里，买方正常领分红；借券人另付分红补偿 |
| 退市 | 退市清算按每股返还金额给持有人；欠券的人按同样的每股金额向出借人现金了结，融券合约结束。融资买入的股票退市后，返还的现金留在账户里，融资欠款照旧 |
| 新股认购 | 只能用自己的可用资金，融资借款和冻结的卖出所得都不能用 |
| 破产重整 | 见 §6 |
| 排行榜 | 按净资产计算，利息和融券费用都是成本 |

## 8. NPC 卖空

价值型 NPC 中的 30%（`npc_short_frac`）开通信用账户，**通过同一个券源、按同样的规则**卖空：

- 价格高于自己心中估值的幅度超过开仓阈值 + 10%（`npc_short_extra`）时，挂限价融券卖出，价格不低于最新价，数量不超过自身财富的 10%（`npc_short_size`）× 信心；
- 价格回到心中估值以下时买券还券；
- 维持担保比例、强平、费用和玩家完全一样，所以 NPC 卖空也会被轧空、被强平。

只给价值型 NPC：他们有估值依据，现实中卖空的主要也是基本面机构（对冲基金），不是散户。其他类型的 NPC 仍然只做多。

## 9. 防薅羊毛

新增的检验机器人（`backend/src/sim/margin_bots.rs`），每个用 3 个种子回放标准输入集：

| 机器人 | 策略 | 要求 |
|---|---|---|
| `lever_hold` | 第一天开通信用账户，等权买入全部股票，再用全部可用保证金融资加仓，一直持有 | 杠杆持有不是机械套利，是承担更大风险换取风险溢价。要求它的超额不超过“杠杆倍数 × 被动收益 − 融资成本”所解释的部分，并报告最大回撤 |
| `short_rich` | 每天卖空价格高出公开估值最多的 5 支股票，价格回到估值以下时还券 | 扣除费用后，相对买入持有的超额 ≤ 5 个百分点 |
| `short_dividend` | 周日晚上卖空即将分红的股票，周一买回 | 分红补偿 + 费用之后不赚钱 |

通用要求：账本总和为 0（每天日结后检查），股数守恒（借出的股票计入借券人的持仓）。

### 验收结果（2026-11-06，合并情绪层第一批之后）

标准输入（inputs33）和世界库，种子 1、7、20261105，全部机器人。相对买入持有的超额（3 个种子平均，百分点；等权 / 市值加权；括号里是等权超额的最小值到最大值）：

| 机器人 | 超额 | 最大回撤 | 最大负债 |
|---|---|---|---|
| `lever_hold` | +6.8 / +0.1（+3.9..+11.7） | 11%–14% | 约 72,000 币（杠杆约 0.72 倍，接近折算率 0.7 时的上限 0.77） |
| `short_rich` | −1.4 / −8.1（−3.6..+1.2） | 5%–8% | 约 54,000–72,000 币 |
| `short_dividend` | −7.6 / −14.3（−9.8..−6.1） | 4%–11% | 约 11,000–20,000 币 |

- 三个种子都没有触发追保、强平或穿仓；每天日结后不变量全部成立（现金总和为 0，股数守恒）。
- `lever_hold` 相对等权基准超过 5 个百分点，相对市值加权基准只有 +0.1。它的融资部分只买标的证券（上市满 5 天、没有退市倒计时、不低于 1 币），等于先筛掉了最差的一批股票；超额主要来自这层筛选和承担的杠杆风险，不是机械套利。按原则 3 的口径，它和 `hold_hottest` 一样，只需不超过市值加权基准。
- `short_dividend` 稳定亏损：分红补偿让分红前卖空拿不到好处。
- NPC 卖空：每季约 1 万笔融券委托，融券费用约 4,400 币，分红补偿约 10 万币。按费率反推，平均融券余额约 17 万币，约为流通市值的 2%（A 股不到 1%，美股中位数约 3%–5%）。
- 与同一程序关闭 NPC 卖空（`--margin npc_short_frac=0`）对照，冷门股 log(价格/估值) 的 95% 分位和“同向偏离 10% 以上最长天数”的 p90：种子 1 为 0.125 → 0.135、10 → 7 天；种子 7 为 0.261 → 0.262、34 → 38 天；种子 20261105 为 0.227 → 0.124、38 → 18 天。卖空在一个种子上明显缩短了偏离，在情绪持续偏热的种子 7 上没有效果。NPC 卖空的三个参数是初始取值，没有按这些指标回调。


## 10. 数据

迁移 V7：

- `credit_accounts`：每个信用账户一行（状态：正常、追保、强平中、已穿仓；追保日；穿仓欠款）。
- `margin_debts`：每个账户每支股票的融资欠款（本金、未付利息）。
- `short_positions`：每个账户每支股票的欠券（数量、冻结的卖出所得、未付费用、出借人）。
- `margin_orders`：信用委托的类型（融资买入、融券卖出、卖券还款、买券还券）。
- `player_days.liabilities`：日结时的负债。

新的流水原因：`margin_loan` 融资借款、`margin_repay` 融资还款、`margin_interest` 融资利息、`lending_fee` 融券费用、`short_dividend` 分红补偿、`short_settle` 融券了结（退市、穿仓时按现金了结）。

## 11. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 关闭后不能开通，已有合约照常计息和了结 |
| `min_days` | 7 | 注册满几天 |
| `min_assets` | 0.5 | 净资产不低于初始资金的比例 |
| `listed_days` | 5 | 标的证券上市满几天 |
| `haircut` | 0.7 | 标的证券的折算率 |
| `margin_ratio` | 1.0 | 融资、融券保证金比例 |
| `interest_spread` | 0.03 | 融资利率 = 政策利率 + 此值 |
| `fee_spread` | 0.05 | 融券费率 = 政策利率 + 此值 |
| `call_ratio` | 1.3 | 追保线 |
| `liquidate_ratio` | 1.1 | 盘中平仓线 |
| `target_ratio` | 1.5 | 强平平到的比例 |
| `protect` | 0.05 | 强平委托的保护价幅度 |
| `lend_frac` | 0.5 | 委员会最多借出的持股比例 |
| `stock_cap` | 0.25 | 单支股票融资余额、融券余量占流通部分的上限 |
| `concentration` | 1.0 | 单支股票的融资融券敞口占净资产的上限 |
| `npc_short_frac` | 0.3 | 可以卖空的价值型 NPC 比例 |
| `npc_short_extra` | 0.10 | NPC 开空仓比开多仓多要求的偏离 |
| `npc_short_size` | 0.10 | NPC 单笔空仓占自身财富的上限 |

### 附：`spoof_scare` 复核（合并后）
