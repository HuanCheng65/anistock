# 安易 AniEx 游戏设计 v1

三条原则（来自社团）：

1. **尽量真实**：用真实世界的制度和经济学、金融学原理解决问题；只有在明显影响理解或上手时才简化，简化处要标出来。
2. **易上手，有深度**：新手看喜欢的番买股票就能玩；高手可以研究数据、估值、挂单、利用规则赚钱。
3. **好玩**：真实和游戏性之间取平衡。

下表每条规则后面标注：现实依据 / 服务哪条原则 / 是否是对原则 1 的简化（⚠️）。

---

## 1. 世界观

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 每个系列是一家上市公司（AniList 续作/前作相连的 TV、网络番、剧场版；例外表 `sim/series.json`），股票代码按上市顺序编号。已上市系列的新一季不发新股，在原本开始认购的那天并入公司（公告），营收和估值按名下作品相加 | 版权方的一个 IP 项目；续作是公司的新项目（docs/design/series.md §3） | 1 |
| 公司营收 = 外部需求 × 该番在三个市场（欧美 AniList、中国 Bangumi、日本 Annict）的加权热度份额。**平台规模的历史满两季（182 天）后改为绝对营收**：营收 = 变现率 × Σ 市场权重 × 作品热度 ÷ 平台规模，平台规模 = 过去一年（采集历史不足一年时用已有的天数）所有采集范围内正在播出作品的每日总热度的平均；切换当天按“当天营收总额不变”定变现率 | 出口经济：真实观众是“外国买家”；长尾作品不再挤占新番的份额（docs/design/series.md §6） | 1 |
| 营收按天入账；扣掉运营成本后交企业所得税 25%；税后利润的 90% 每周日作为分红发放，其余留存为公司净资产 | 现实的分红制度 | 1 |
| 番剧完结后进入长尾：完结后几周从播出期水平回落，之后是“底 + 两段衰减的超出部分”（欧美：完结一年后约为完结时水平的 8%，三年后约 5%，底约 2.4% 且多年不再下降；中国按 Bangumi 收藏活跃度，更高）。评分高、网络番（ONA）的长尾更高。估值把长尾一直算到无限期（400 天以后用闭式求和） | 2018–2025 年约 1,500 部番的完结后数据，按平台规模平减（`sim/calibration/valuation_filter.md`“Long tail”） | 1 |
| 退市：名下作品全部完结、最近一周营收低于正在播出的公司营收中位数的 1%、且 3 年内公布续作的概率低于 10%（已公布续作的不退市），连续 8 周后退市：按每股净资产把现金返还给持有人 | 现实的退市清算；按绝对水平而不是占全市场的比例，长尾公司越来越多也不会把新番挤出去（docs/design/series.md §9） | 1 |
| 成人向作品（AniList 标为成人或 Hentai 类型）不上市；已上市的在下一次日结按当天收盘价收回全部股份，认购中的取消发行并全额退款 | 交易所的上市准入 | 1 |
| 游戏内货币叫“币”，和真实货币无任何对应，不能充值、不能提现 | — | 安全 |

## 2. 交易规则

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 连续竞价撮合：价格优先、时间优先；支持限价单、市价单；可部分成交、可撤单 | 交易所撮合制度 | 1、2 |
| 最小交易单位 1 股 | A 股是 100 股一手 ⚠️ 简化：一手的门槛对游戏没有意义 | 2 |
| T+0：当天买入当天可卖 | 港股、美股是 T+0；A 股是 T+1 | 2、3 |
| **不设每日涨跌停**，改用冷静期：当天第一次有成交价偏离 5 分钟前的价格超过 10% 时，这笔不成交，股票冷静 5 分钟，期间只能在参考价 ±10% 内成交；之后以当天开盘价为锚，偏离超过 20%、30%……依次再触发 | 港股市场波动调节机制（VCM）；以开盘价为锚的逐级扩大是为防止小市场里被大户一路推高 ⚠️ | 1、3：神回/崩坏当天就能反映到价格上 |
| **开盘集合竞价** 08:45–09:00：只收限价单、不撮合，页面显示参考开盘价；09:00 按成交量最大的唯一价格撮合，之后进入连续交易。没有可成交的单子时，以昨收为开盘价 | A 股集合竞价、港股开市前时段 | 1、3：公平消化收盘后（04:00–08:45）的消息，不比谁起得早 |
| 交易时间：08:45–09:00 集合竞价，09:00 至次日 04:00 连续交易，算作同一个交易日；交易日在凌晨 04:00 切换（委托、成交、K 线、涨跌幅、分红登记都按交易日），06:30 日结 | ⚠️ 简化：真实交易所只开几个小时；社团成员晚上才有空，深夜番大约 22:00–01:00 播出，热度快讯在播出后 1–3 小时出来，夜盘让玩家能对它交易 | 3 |
| 佣金 0.025%（买卖双方），卖出印花税 0.05% | A 股现行费率；⚠️ 简化：没有每笔最低佣金，小额交易对新手更友好 | 1、2 |
| 委托当日有效：每日结算时撤销所有未成交委托 | A 股委托当日有效 | 1 |
| **融资融券**：开通信用账户（净资产不低于 50,000 币）后可以融资买入、融券卖出。保证金比例 100%，标的股票折算率 70%；融资利率 = 政策利率 + 3%，融券费率 = 政策利率 + 5%，按日计息 | A 股融资融券（保证金比例 100%、折算率最高 70%、资产门槛）；美股保证金账户（一个账户，全部资产作担保）。要求完成身份验证（A 股两融要求开户满 6 个月；这里不设等待期，用一人一号的身份验证防止注册即用的小号加杠杆，`[margin] min_days` 保留为开关，默认 0）、风险测评 C4 及以上、通过 10 题的知识测试（答对 8 题）、签署《融资融券风险揭示书》（A 股两融开户的适当性要求）；不分普通账户和信用账户 | 1、2：看好可以加杠杆，看空可以卖空，高估的股票有人卖 |
| 融券的券源是制作委员会的持股（最多借出 50%），费用和分红补偿付给出借人（流出经济）；单支股票融资余额、融券余量不超过流通部分的 25% | 转融通和证券出借；沪深交易所 25% 的暂停线 | 1 |
| 融券卖出价格不低于最新价，只能限价；卖出所得冻结，只能用于买券还券；不能同时持有和融券同一支股票 | A 股融券卖出的价格限制和资金用途限制 | 1：卖空不能连续砸价 |
| 维持担保比例 =（现金 + 持仓市值）÷ 负债。低于 130% 日结时追保，下次日结仍低于则强制平仓；盘中低于 110% 或净资产为负立即强制平仓，在连续交易时段每分钟按保护价（±5%）平到 150% | A 股 130% 追保线和券商的平仓线。⚠️ 追保期限压缩为 1 天 | 1 |
| 穿仓：持仓卖完仍资不抵债，剩余负债由破产重整核销（不受每季一次的限制），本段收益记为 −100% | 现实中客户仍欠券商；游戏里没有追偿。⚠️ | 3 |
| 详细规则见 `docs/design/margin.md` | — | — |

## 3. 账户与税

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 注册需要完成工作量证明（防脚本批量注册），可以切换为需要邀请码或暂停注册；每人一个账号，初始 100,000 星辉 | — | 防小号 |
| **身份验证**：目前通过绑定 QQ 完成（一个 QQ 只能绑定一个账号）。财政补贴、新股认购、排行榜、融资融券都要求完成身份验证，具体验证方式与这些门槛分开（`backend/src/kyc.rs`） | 券商开户的实名认证、一人一户 | 1、3：小号拿不到好处 |
| 现金自动按存款利率计息（政策利率 − 1%），每日计提 | 活期存款 | 1 |
| 股息红利税按持股时间差别征收：当天买入当天拿到分红 20%，持有不满 4 周 10%，满 4 周免税；先进先出计算持有时间 | A 股差别化股息税（1 个月以内 20%、1 个月到 1 年 10%、1 年以上免税）。⚠️ 简化：期限按游戏时间压缩。一部番大约只播一季，按现实的“1 年免税”去压缩会让免税档根本够不着，税就成了所有持股者的隐性成本 | 1、2：鼓励持有，不鼓励为分红短炒 |
| 排行榜只排完成身份验证、至少成交过 1 笔的玩家（`[account.eligibility]`，成交笔数 `rank_min_trades` 默认 1，只用来挡掉从没交易过、收益率停在 0 的账号；注册天数 `rank_min_days` 默认 0：身份验证已经挡住小号，等待期只会让新玩家两周看不到自己的排名）。按累计收益率排名。没有重整过的玩家，收益率 =（总资产 − 初始资金）÷ 初始资金，顺序与按总资产（现金 + 持仓市值 − 融资融券负债，即净资产）相同；财政补贴、分红、利息都算收益，融资利息、融券费用都是成本 | — | 3 |
| **程序化交易**：玩家可以在设置里生成 API 密钥，用脚本读取数据；交易权限要求完成身份验证、签署《程序化交易风险揭示书》。下单和撤单每秒 5 次、每天 5,000 笔、同时 100 笔未成交（单支股票 20 笔），网页和密钥合计。用密钥下过单的账号在排行榜上标“程序化”，不单独排名（`docs/design/api-access.md`，开发者说明 `docs/api-scripts.md`） | 交易所的 API Key 和权限分级；证监会 2024 年《证券市场程序化交易管理规定（试行）》的报告和识别要求；交易所不把算法交易单独排名 | 1：会写程序的玩家有正规入口，做市商和 NPC 不被程序薅（门禁检验，`docs/design/api-access.md` §7） |
| 破产重整：总资产（现金含冻结 + 持仓按最新价）低于初始资金的 10%（`restructure_threshold`）时，可在连续交易时段自愿申请，每季（1/4/7/10 月 1 日起，按交易日）最多一次。撤销全部委托和未配售的新股认购，全部持仓按最新价转给 world 账户（不是委托，不收佣金和印花税），现金由 world 账户补足到初始资金。排行的收益率按时间加权连乘：每次重整结束一段，累计收益率 = 各段（期末 ÷ 期初）连乘 × 当前总资产 ÷ 本段期初 − 1；亏到 10,000 币（−90%）后重整再赚 10%，累计是 0.1 × 1.1 − 1 = −89%。排行和“我的”显示重整次数。只在连续交易时段开放，因为休市时最新价还没反映隔夜消息，可能被用来按旧价甩掉预期低开的股票 | 破产重整（债务人重新开始，记录留存）；时间加权收益率（基金业绩披露按子期间连乘，剔除申购赎回等外部现金流的影响）。⚠️ 简化：注资来自 world 账户而不是债权人让步；world 账户之后持有这些股票，照常收分红、参加退市回购 | 3：亏光的人还能继续玩，但不能靠重整刷排名 |

## 4. 宏观

| 规则 | 现实依据 | 原则 |
|---|---|---|

| 财政：税收的 25% 用于转移支付（财政补贴），按人头平均分给居民：NPC 投资者，以及完成身份验证、注册满 7 天、过去 28 天有成交的玩家；不符合条件的玩家不领，份额由其他人平分。其余沉淀 | 财政转移支付；福利要求居住或参保年限 | 1：不凭空给玩家发钱 |
| 每周外部需求的总量随 AniList 全市场热度变化（季度景气） | 真实世界的景气周期 | 1 |
| 宏观参数来自 96 组仿真的筛选结果（`sim/params_recommended.toml`）：控制 M2 主要靠控制注入规模 | 仿真结论 | 1 |
| 公司营收的 50% 是运营成本（发行、制作、宣传），付给外部；税后利润的 90% 每周分红 | 单一 IP 项目公司接近特许权信托，几乎全额分配 | 1 |
| 规模：每周外部需求 162 万币（原 250 万币；第一阶段加入长尾后，一部番的价值约翻倍，按“切换当天市场总估值不变”缩放：回放 7/8 两版模型都估值的 68 家公司，旧 ÷ 新 = 0.648，10/1 复核 0.625），每家公司 1 万股。按仿真，股价中位数约 5 币，公开发行部分总值约为 40 名玩家现金的 0.7 倍 | 股票和现金同一量级，价格才会跟着基本面走；所有 NPC 和做市商的资金都是按这个规模标定的，估值变大而资金不变时套利不足，价格偏离估值更大更久 | 1、3 |

## 5. 上市与市场参与者

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 新番在首播前 21 天上市（认购在上市前 3 天），发行价 = 同一估值模型按开播前的估计（§6）算出的价值，不再额外打折 | 现实的新股折价补偿不确定性；这里模型的价值已经计入不确定性（实测上市后四周的价值按市值加权平均是定价时的 0.94 倍），再打折只是白送认购者 ⚠️ | 1 |
| 开服时每支股票的开市参考价按开服当天的经营数据定价；开服前的 K 线是数据回放，整条按比例缩放到正好接上开市参考价（形状和涨跌幅不变） | — | 3 |
| 每家公司 10,000 股；25% 公开发行，75% 由“制作委员会”持有 | A 股最低公开发行比例 25% | 1 |
| 制作委员会就是真实世界的版权方：它拿到的分红**流出游戏经济**；IPO 募资里的制作费付给真实的动画公司，也流出经济 | 利润汇回海外、向外部供应商付款 | 1：这两个“下水道”让股票总值和玩家现金保持同一量级，否则钱多股少，价格会脱离基本面 |
| **新股公开认购**：上市前 3 天开放认购，按发行价冻结资金，可改数量或撤回。需要完成身份验证；每支新股的认购金额（数量 × 发行价）不超过认购额度，额度 = 认购前 5 个交易日的日均持仓市值。截止当天日结时分配：公开发售基础是流通盘的 50%，超额认购 15/50/100 倍时回拨到 70%/80%/90%；超额时按比例分配，零头抽签；没卖出的由制作委员会留下。次日上市 | 港股公开发售 + 抽签 + 回拨机制；认购额度参照 A 股市值配售（前 20 个交易日日均市值）。⚠️ 港股基础比例是 10%，社团玩家少，放大到 50%；市值天数按游戏时间压缩 | 1、3：奖励眼光而不是谁在线；“打新”本身好玩 |
| **做市商（NPC）**：每支股票一个指定做市商，围绕最新成交价双边报价，两边各挂五档，每档有最小数量；最近波动越大价差越宽（波动扣除成交价在买卖价之间来回跳的部分），开播前后等信息集中的时段报价放宽；库存偏离目标时调整报价数量；库存卖完后从同一个券源借券继续报卖价（欠券不超过总股数的 20%），价格回落时先买券还券；资金和持仓有限，会亏钱 | 指定做市商制度：持续双边报价义务，科创板做市商可通过转融通借券；Roll 价差模型 | 1、2 |
| **制作委员会（NPC）**：持有原始股，股价超过自己估计价值的 1.3 倍时少量减持（不回购） | 大股东减持 | 1 |
| **NPC 投资者（v0.3.0 起）**：几百个，按挂牌数量等比例放大；分四类：看价值的（各自看法 = 估值 × 个人偏差，偏差缓慢变化）、追趋势的、看新闻的（估值大幅修正和快讯后入场）、散户（随机）。各自有资金和持仓上限，不卖空；行动频率随时段变化，晚上最活跃 | 现实市场的参与者结构 | 1、3：盘口一直有人，价格跟着信息走 |
| **情绪层（docs/design/sentiment.md）**：情绪只改变 NPC 的买卖，不改估值。① 散户偏爱正在被讨论的股票：首播当晚、热度快讯、进入涨幅或跌幅榜后买入的比例上升，是否出现、强弱、持续几小时都随机；② 看新闻的 NPC 对一次超预期反应不足，同方向连续超预期时反应过度，幅度和持续时间随机；③ 全市场情绪以几周为周期随机冷热交替，市场页公开为冷淡 / 平稳 / 火热，情绪火热时散户和追涨型更敢买，冷门股更敏感；④ 热门股 5 个交易日涨 25% 以上时，约一半会形成追涨泡沫：追涨型和散户涌入，几天内随机破裂后抛售，是否形成、强弱、何时破裂都随机，不公开；⑤ 散户按自己的成本价卖出：浮盈的持仓比浮亏的更容易卖（1.5 倍），卖出总量不变 | Barber–Odean 注意力驱动买入；Barberis–Shleifer–Vishny、De Bondt–Thaler 反应不足与过度反应；Baker–Wurgler 投资者情绪；De Long 等正反馈交易、Greenwood–Shleifer–You 涨势后的崩盘概率；Shefrin–Statman、Odean 处置效应 | 1、3：价格围绕价值有涨有落，又没有一条记住就能赚的规律 |
| NPC 的资金：现金太少时从外部补进，太多时流回外部（每周有上限） | 资金在市场之间流动 | 1：NPC 的财富不会因规则漏洞单向增减 |
| 估值的**方法公开**（本文 §6 和仓库代码），页面只展示原始数据（营收、分红、热度、观众数、集数）和快讯 | 现实中估值方法公开，结论各有不同 | 2：新手凭喜好，高手自己算 |
| **面值退市**：收盘价连续 20 个交易日低于 1 币即退市清算（第 10 天发警示公告）；低价股的冷静期区间至少上下各 1 分，保证价格能动 | 港股、A 股的面值 / 低价退市 | 1 |
| **公司资本政策**（docs/design/corporate.md §3）：管理层按公开规则行事，它的估计就是隐藏估值。**拆股**：收盘价连续 5 个交易日高于 100 币，公告后 7 天生效，1 拆 2/3/4/5/10（拆后最接近全市场中位数）。**配股**：续作公布时付制作费（续作这一季价值的 20%），先用现金，不够的配股（收盘价八折，每 10 股最多配 3 股，3 天认购，登记、缴款、发股在同一次日结完成）；未认购的部分由制作委员会按除权参考价接手，差价补给未认购的人，融券欠券补偿出借人。**回购**：周日检查，闲置现金不少于市值 1% 且股价低于价值时，3 个月内用闲置现金在市场上买回注销，价格不高于 30 日均价的 1.5 倍和公司估计的价值，每天不超过 20 日均量的 25%，开盘后、收盘前 30 分钟不买 | 名义股价之谜、东证的最小投资单位要求；优序融资（Myers–Majluf）、港股上市规则 7.21 补偿安排、A 股配股上限 30%；自由现金流（Jensen）、回购信号、SEC Rule 10b-18、上市公司股份回购规则。⚠️ 配股登记前认购、不停牌；每一季制作费按同一比例 | 1、2 |
| **K 线前复权**：拆股、配股之前的价格按复权因子换算，可切换为不复权；分红不复权 | 行情软件的前复权 | 2 |

## 6. 估值（v0.3.0 起）

NPC、发行价、热度快讯都用同一个估值。完整说明见 `docs/design/valuation.md`，参数和校准结果见 `sim/calibration/valuation_filter.md`。

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 一部番在每个市场的热度 = 作品水平 × 集内曲线。作品水平用卡尔曼滤波估计：开播前从“想看”人数出发，每有新数据就按“超出预期多少”修正，越不确定修正越多，噪声大的数据修正少。欧美的数据从一集播出后第 2 天起每天计入，不等整周（v0.6.1）。一个市场超预期会按拟合的相关带动其他市场：中国和日本之间相关强，它们和欧美之间弱（v0.6.1 起分别拟合）。开播满 4 周时按欧美热度分三档，热门一档之后的预期衰减更慢（v0.6.1，按 2018–2025 年历史数据）。完结前一周观众补番、热度上升，计入预期，不当作作品变热（v0.6.1） | 分析师根据业绩超预期修正盈利预测 | 1：只有新信息会改变估值，按日历交易赚不到钱 |
| 欧美数据按每集一周的平均值观测；中国、日本按每周数据更新时观测。参数用上一季的完整数据按最大似然估计，80% 预测区间的实际覆盖率约 80%（留出的作品上检验） | — | 1 |
| 估值 = 未来每天预期分红的折现之和 + 公司账上的现金（每股）。份额是相对的：正在播的番一起随时间衰减，下一季（1、4、7、10 月）开始时新番补上 | 股利折现模型 | 1 |
| 折现率 = 政策利率 + 股权风险溢价 30%（年化） | 小盘、高波动、可能退市的股票要求更高的风险溢价。⚠️ 简化：比整个股市的溢价（约 8%）高得多，换来被动持有每季能有几个百分点的收益 | 1、2 |
| 每周日发分红，估值按每股分红下调（除息），价格的下跳有据可查 | 除息 | 1 |
| **热度快讯**：新集播出后每小时抓一次单集吐槽数，按“播出后第几小时通常有多少”的曲线（用 Bangumi 吐槽的发帖时间校准）换算成对这一集热度的观测，立即修正估值；超出或低于预期 20% 以上时发快讯 | 盘中公告 | 1、3 |
| **排期与新闻事件**（docs/design/corporate.md §2）：未播各集按公开排期（Bangumi 各集日期，下一集以 AniList 核对）计入估值；下一集推后时公告延期，收入后移；AniList 状态为暂停时公告暂停播出，剩余各集按约 10 个月后恢复估值 ⚠️；续作公布按第一阶段的规则。炎上没有可靠信号，不做 | 分析师按电视台排期预测；新闻是对模型的修正，同一入口 | 1 |
| 长篇连载（播了很久的番）按每周约 0.5% 的速度衰减 | — | 1 |

## 技术架构

- **服务端**：Python FastAPI + SQLite（`data/game.db`，和采集器的 `anistock.db` 分开，后者只读），uvicorn，systemd 用户服务。
- **经济引擎**：`engine/` 包，营收、估值、账本、央行逻辑。仿真（`sim/`）和游戏服务共用同一份代码。
- **时钟**：实时模式（每天 06:30 日结，接在采集器之后）；回放模式用于测试和开服前生成历史 K 线。
- **并发**：所有写操作（玩家下单、NPC 挂单、日结）经过同一把异步锁，事务很短。
- **前端**：Vue 3 + Vite + TypeScript，vue-router 管页面，Pinia 管状态；图表用 lightweight-charts（npm 安装、打包进产物，不依赖 CDN）。行情每几秒轮询一次。服务器装一次 Node 即可构建（`npm ci && npm run build`），FastAPI 直接托管构建出的静态文件。
- **作品匹配**：每季开始时手动运行 `uv run sim/match.py --search` 并提交 `sim/matches.json`、`tracked_extra.json`；服务器的每日结算只刷新 Annict 播出时间并重建市场序列，不改任何 git 跟踪的文件。
- **数据合规**：页面只展示聚合统计，不展示任何平台的用户名或评论；封面图不转存。
