# AniStock 游戏设计 v1

三条原则（来自社团）：

1. **尽量真实**：用真实世界的制度和经济学、金融学原理解决问题；只有在明显影响理解或上手时才简化，简化处要标出来。
2. **易上手，有深度**：新手看喜欢的番买股票就能玩；高手可以研究数据、估值、挂单、利用规则赚钱。
3. **好玩**：真实和游戏性之间取平衡。

下表每条规则后面标注：现实依据 / 服务哪条原则 / 是否是对原则 1 的简化（⚠️）。

---

## 1. 世界观

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 每部番是一家上市公司，股票代码按上市顺序编号 | 项目公司 / 制作委员会 | 1 |
| 公司营收 = 外部需求 × 该番在三个市场（欧美 AniList、中国 Bangumi、日本 Annict）的加权热度份额 | 出口经济：真实观众是“外国买家” | 1 |
| 营收按天入账；扣掉运营成本后交企业所得税 25%；税后利润的 90% 每周日作为分红发放，其余留存为公司净资产 | 现实的分红制度 | 1 |
| 番剧完结后营收按实测曲线衰减（完结后第 1 周约为正常播出周的 40%，之后每周约 ×0.78） | 实测 30 部夏番 | 1 |
| 营收低到一定程度、连续 8 周后退市：按每股净资产把现金返还给持有人 | 现实的退市清算 | 1 |
| 游戏内货币叫“币”，和真实货币无任何对应，不能充值、不能提现 | — | 安全 |

## 2. 交易规则

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 连续竞价撮合：价格优先、时间优先；支持限价单、市价单；可部分成交、可撤单 | 交易所撮合制度 | 1、2 |
| 最小交易单位 1 股 | A 股是 100 股一手 ⚠️ 简化：一手的门槛对游戏没有意义 | 2 |
| T+0：当天买入当天可卖 | A 股是 T+1 ⚠️ 简化：社团成员上线时间零碎，T+1 会让人买完就不能动；**留给社团决定** | 2、3 |
| 单日涨跌幅上限 ±10%，以前一日收盘价为基准 | A 股主板 | 1 |
| 新股上市前 5 个交易日不设涨跌幅限制 | A 股注册制 | 1 |
| 交易时间：每天 09:00–23:00 连续交易，06:30 日结 | ⚠️ 简化：真实交易所只开 4 小时；社团成员晚上才有空 | 3 |
| 佣金 0.025%（每笔最低 0.1 币），卖出印花税 0.05% | A 股现行费率 | 1 |
| 委托当日有效：每日结算时撤销所有未成交委托 | A 股委托当日有效 | 1 |
| 不能卖空、不能加杠杆（v1） | 融资融券是后续解锁内容 | 2 |

## 3. 账户与税

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 注册需要社团邀请码；每人初始 100,000 币 | — | 防小号 |
| 现金自动按存款利率计息（政策利率 − 1%），每日计提 | 活期存款 | 1 |
| 股息红利税按持股时间差别征收：持有 ≤1 周 20%，1 周–1 季 10%，>1 季免税；先进先出计算持有时间 | A 股差别化股息税（时间按游戏节奏缩短） | 1、2：鼓励长期持有，高手会算 |
| 排行榜按总资产（现金 + 持仓市值）排名 | — | 3 |

## 4. 宏观

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 央行每周日根据过去 28 天 M2 年化增速调整政策利率，每次最多 ±0.25%，目标增速 20% | 货币供应量目标制 | 1 |
| 财政：税收的 25% 用于转移支付（新人补贴），其余沉淀 | 财政转移支付 | 1 |
| 每周外部需求的总量随 AniList 全市场热度变化（季度景气） | 真实世界的景气周期 | 1 |
| 宏观参数来自 96 组仿真的筛选结果（`sim/params_recommended.toml`）：控制 M2 主要靠控制注入规模 | 仿真结论 | 1 |
| 公司营收的 50% 是运营成本（发行、制作、宣传），付给外部；税后利润的 90% 每周分红 | 单一 IP 项目公司接近特许权信托，几乎全额分配 | 1 |
| 规模：每周外部需求 250 万币，每家公司 1 万股。按仿真，股价中位数约 5 币，公开发行部分总值约为 40 名玩家现金的 0.7 倍 | 股票和现金同一量级，价格才会跟着基本面走 | 1、3 |

## 5. 上市与市场参与者

| 规则 | 现实依据 | 原则 |
|---|---|---|
| 新番在首播前 21 天上市，发行价 = 系统按开播前热度估算的价值 × 90% | IPO 折价发行 | 1 |
| 每家公司 10,000 股；25% 公开发行，75% 由“制作委员会”持有 | A 股最低公开发行比例 25% | 1 |
| 制作委员会就是真实世界的版权方：它拿到的分红**流出游戏经济**；IPO 募资里的制作费付给真实的动画公司，也流出经济 | 利润汇回海外、向外部供应商付款 | 1：这两个“下水道”让股票总值和玩家现金保持同一量级，否则钱多股少，价格会脱离基本面 |
| 上市当天公开发行部分以发行价挂在卖盘上，先到先得 | ⚠️ 简化：现实是申购中签；先到先得更好理解，抢新股本身也好玩 | 2、3 |
| **做市商（NPC）**：每支股票一个，在自己估计的价格上下双边挂单，库存多了会压价；资金和持仓有限，会亏钱 | 做市商制度 | 1、2 |
| **制作委员会（NPC）**：持有原始股，股价明显高于自己估计的价值时减持，明显低于时回购 | 大股东减持 / 回购 | 1 |
| **散户（NPC）**：少量随机买卖，让盘口有生气 | 噪声交易者 | 3 |
| NPC 用的是系统内部估值加上噪声和滞后，**不公开**。页面只展示原始数据（营收、分红、热度、观众数、集数） | 现实中没人知道“真实价值” | 2：新手凭喜好，高手自己算 |

## 6. 页面

- **行情**：全部股票，涨跌幅、成交额、本周营收变化、迷你走势
- **个股**：K 线（日线 + 当日分时）、五档盘口、下单、基本面（三个市场的营收构成和走势、历史分红、已播/总集数、下一集时间、观众规模）、公司公告
- **我的**：持仓（成本、浮动盈亏、累计分红）、委托、成交记录
- **排行榜**、**新闻**（开播、完结、分红、利率决议、新股上市、退市）
- **新手指南**：五分钟上手；**规则**：本文档的玩家版

## 7. 留给社团决定的事

- T+0 还是 T+1
- 开播首周是否放开涨跌幅（`airing_free_days`，目前关闭）
- 三个市场的权重（目前中国 50%、欧美 30%、日本 20%）
- 交易时间
- 赛季：多久一季、资金是否部分重置
- 新股发行方式：目前是上市当天按发行价先到先得，奖励的是“谁在线”而不是眼光。更真实的替代：承销商在不设涨跌幅的 5 天里逐步放出；或者照搬 A 股的申购抽签

## 8. 以后解锁（不在 v1）

国债与央票、融资融券（杠杆与做空）、指数与 ETF、玩家基金、期货期权、角色币。

## 技术架构

- **服务端**：Python FastAPI + SQLite（`data/game.db`，和采集器的 `anistock.db` 分开，后者只读），uvicorn，systemd 用户服务。
- **经济引擎**：`engine/` 包，营收、估值、账本、央行逻辑。仿真（`sim/`）和游戏服务共用同一份代码。
- **时钟**：实时模式（每天 06:30 日结，接在采集器之后）；回放模式用于测试和开服前生成历史 K 线。
- **并发**：所有写操作（玩家下单、NPC 挂单、日结）经过同一把异步锁，事务很短。
- **前端**：Vue 3 + Vite + TypeScript，vue-router 管页面，Pinia 管状态；图表用 lightweight-charts（npm 安装、打包进产物，不依赖 CDN）。行情每几秒轮询一次。服务器装一次 Node 即可构建（`npm ci && npm run build`），FastAPI 直接托管构建出的静态文件。
- **作品匹配**：每季开始时手动运行 `uv run sim/match.py --search` 并提交 `sim/matches.json`、`tracked_extra.json`；服务器的每日结算只刷新 Annict 播出时间并重建市场序列，不改任何 git 跟踪的文件。
- **数据合规**：页面只展示聚合统计，不展示任何平台的用户名或评论；封面图不转存。
