# 情绪层

估值（docs/v2-valuation.md）回答“这部番值多少”，要尽量准；情绪层回答“市场此刻愿意出多少”，让价格围绕估值有涨有落。本文定义情绪层的范围、机制和验收。状态：已定方案，待第 1 项（估值对热度反应慢）修完后实施。

---

## 1. 原则

1. **情绪只作用于 NPC 的买卖，不改隐藏估值。** 价格偏离估值多远，由价值型 NPC 和做市商兜底，最终回归。
2. **每种现象都有现实研究依据**，在游戏里有可观察的表现。
3. **不存在机械规则就能白赚的空间。** 强度、时长、是否发生都随机抽取；每种现象配一个专门的检验机器人。
4. **市场整体特征要像真的**（§4），这是“股市味”的客观标准。

## 2. 机制

### 第一批

| 现象 | 现实依据 | 实现 | 表现 |
|---|---|---|---|
| 注意力驱动 | Barber & Odean：散户偏爱买正在被讨论的股票 | 首播当晚、热度快讯、上热榜时，散户 NPC 的买入概率随关注度上升，强度随机 | 关注高峰时短暂溢价，随后消退 |
| 反应不足与过度反应 | Barberis, Shleifer & Vishny；De Bondt & Thaler | 消息型 NPC 对单条超预期反应打折；同方向的连续超预期使反应放大，偏离随机，回归速度随机 | 第一次超预期涨不够，连续超预期涨过头后回调 |
| 全市场情绪周期 | Baker & Wurgler 投资者情绪；对难估值的小盘股影响更大 | 一个缓慢变化的全市场情绪（AR(1)），调节散户和追涨型 NPC 的风险偏好；冷门股的敏感度更高 | 几周尺度的小牛市、小熊市 |

情绪指标对玩家公开为粗略档位：**冷淡 / 平稳 / 火热**，不给数值。

### 第二批（第一批稳定后）

| 现象 | 现实依据 | 实现 |
|---|---|---|
| 追涨泡沫 | De Long 等，正反馈交易 | 热度与涨势叠加时追涨型 NPC 增加，泡沫按随机风险率破裂 |
| 处置效应 | Shefrin & Statman | 散户 NPC 按自己的成本价决定卖出：浮盈时卖压上升，浮亏时惜售 |

### 以后（新闻事件接入后）

| 现象 | 现实依据 | 实现 |
|---|---|---|
| 利好出尽 | 买预期，卖事实 | 已知事件（完结、续作公告）前期待溢价累积，事件后回落；溢价大小与是否出现随机 |

## 3. 防止被利用

每种现象对应检验机器人，3 个种子取平均，扣交易成本后相对买入持有（等权与市值加权）超额不超过 5 个百分点：

| 机器人 | 针对 |
|---|---|
| fade_flash | 快讯后反向操作 |
| ride_flash | 快讯后顺势追入 |
| momentum_k | 追过去 k 天涨幅最高的股票 |
| contrarian_k | 买过去 k 天跌幅最大的股票 |
| sentiment_timer | 按情绪档位择时进出 |
| premiere_rush | 首播前买、首播后卖 |
| hold_hottest | 一直持有热度最高的几只 |

原有机器人与资金检验全部继续通过。高手的优势应来自判断（这次快讯有多强、泡沫还能撑多久），而不是一条可以记住的规律。

## 4. 验收：市场特征

| 特征 | 要求 |
|---|---|
| 波动聚集 | 日收益绝对值的自相关显著为正，并缓慢衰减 |
| 肥尾 | 日收益峰度明显大于 3 |
| 短期反转 | 日内到一天：收益自相关轻微为负 |
| 中期动量 | 几周：价格相对估值的偏离有持续性，但会回归，半衰期有上限 |
| 量与关注 | 成交量与热度正相关，关注高峰伴随放量 |
| 偏离有界 | 价格 / 估值的分位数在设计范围内，不出现长期单向偏离 |

## 5. 前置条件

先修“估值对热度反应慢”（估值本身的偏差，属于模型错误）。理性部分修好后再加情绪，才能分清哪些偏离是设计的，哪些是 bug。
