# 情绪层

估值（docs/v2-valuation.md）回答“这部番值多少”，要尽量准；情绪层回答“市场此刻愿意出多少”，让价格围绕估值有涨有落。本文定义情绪层的范围、机制和验收。状态：第一批已实现（§6），第二批未开始。

---

## 1. 原则

1. **情绪只作用于 NPC 的买卖，不改隐藏估值。** 价格偏离估值多远，由价值型 NPC 和做市商兜底，最终回归。
2. **每种现象都有现实研究依据**，在游戏里有可观察的表现。
3. **不存在机械规则就能白赚的空间。** 强度、时长、是否发生都随机抽取；每种现象配一个专门的检验机器人。
4. **市场整体特征要像真的**（§4），这是“股市味”的客观标准。

## 2. 机制

### 第一批

| 现象 | 现实依据 | 实现 | 表现 |
|---|---|---|---|
| 注意力驱动 | Barber & Odean：散户偏爱买正在被讨论的股票 | 首播当晚、热度快讯、上热榜时，散户 NPC 的买入概率随关注度上升，强度随机 | 关注高峰时短暂溢价，随后消退 |
| 反应不足与过度反应 | Barberis, Shleifer & Vishny；De Bondt & Thaler | 消息型 NPC 对单条超预期反应打折；同方向的连续超预期使反应放大，偏离随机，回归速度随机 | 第一次超预期涨不够，连续超预期涨过头后回调 |
| 全市场情绪周期 | Baker & Wurgler 投资者情绪；对难估值的小盘股影响更大 | 一个缓慢变化的全市场情绪（AR(1)），调节散户和追涨型 NPC 的风险偏好；冷门股的敏感度更高 | 几周尺度的小牛市、小熊市 |

情绪指标对玩家公开为粗略档位：**冷淡 / 平稳 / 火热**，不给数值。

### 第二批（第一批稳定后）

|---|---|---|
| 追涨泡沫 | De Long 等，正反馈交易 | 热度与涨势叠加时追涨型 NPC 增加，泡沫按随机风险率破裂 |
| 处置效应 | Shefrin & Statman | 散户 NPC 按自己的成本价决定卖出：浮盈时卖压上升，浮亏时惜售 |

| 现象 | 现实依据 | 实现 |
|---|---|---|
| 利好出尽 | 买预期，卖事实 | 已知事件（完结、续作公告）前期待溢价累积，事件后回落；溢价大小与是否出现随机 |

## 3. 防止被利用

每种现象对应检验机器人，3 个种子取平均，扣交易成本后相对买入持有（等权与市值加权）超额不超过 5 个百分点：

| 机器人 | 针对 |
|---|---|
| fade_flash | 快讯后反向操作 |
| ride_flash | 快讯后顺势追入 |
| momentum_k | 追过去 k 天涨幅最高的股票 |
| contrarian_k | 买过去 k 天跌幅最大的股票 |
| sentiment_timer | 按情绪档位择时进出 |
| premiere_rush | 首播前买、首播后卖 |
| hold_hottest | 一直持有热度最高的几只 |

原有机器人与资金检验全部继续通过。高手的优势应来自判断（这次快讯有多强、泡沫还能撑多久），而不是一条可以记住的规律。

## 4. 验收：市场特征

| 特征 | 要求 |
|---|---|
| 波动聚集 | 日收益绝对值的自相关显著为正，并缓慢衰减 |
| 肥尾 | 日收益峰度明显大于 3 |
| 短期反转 | 日内到一天：收益自相关轻微为负 |
| 中期动量 | 几周：价格相对估值的偏离有持续性，但会回归，半衰期有上限 |
| 量与关注 | 成交量与热度正相关，关注高峰伴随放量 |
| 偏离有界 | 价格 / 估值的分位数在设计范围内，不出现长期单向偏离 |

## 5. 前置条件

先修“估值对热度反应慢”（估值本身的偏差，属于模型错误）。理性部分修好后再加情绪，才能分清哪些偏离是设计的，哪些是 bug。

## 6. 第一批的实现

代码在 `backend/src/market/`（`mod.rs` 的“sentiment layer”一节），参数在 `server/game.toml` 的 `[market]`。代码里的默认值全部关闭，`game.toml` 打开；关掉任何一项，NPC 的行为和随机数序列与没有情绪层时完全一样。

### 6.1 机制

**全市场情绪**（Baker–Wurgler）。每个交易日一个值 S，是单位方差的日 AR(1)，半衰期 14 天。S 是（种子、服务器密钥、日期）的纯函数：不用存储，重启后不变；密钥不在仓库里，所以玩家无法从公开的种子算出未来的情绪。S 只改变两类 NPC：

- 散户：买入的比例从 50% 变为 50% × (1 + tanh x)，买入金额乘以 eˣ；
- 追涨型：追涨门槛乘以 e⁻ˣ，仓位乘以 eˣ，止损门槛乘以 eˣ。

其中 x = 强度 × S × 敏感度。敏感度 ∝ (1 / 热度)^0.5，截在 0.5–2 之间，再缩放到全市场平均为 1：最冷门的股票是最热门的 4 倍。价值型 NPC、做市商、制作委员会不受影响，它们把价格拉回估值。

玩家看到的档位：S < −0.67 为冷淡，S > 0.67 为火热，其余为平稳（−0.67 和 0.67 是标准正态的四分位点：平稳占一半，冷淡、火热各占四分之一）。档位在 `GET /api/v1/market/status` 的 `sentiment` 字段，市场页指数栏显示。

**注意力驱动买入**（Barber–Odean）。买入要从全市场挑，卖出只在自己的持仓里挑，所以被关注的股票主要被买入。三种触发：首播当晚（第 1 集的播出时间）、发布热度快讯、进入市场页的涨幅或跌幅前 6 名（上热榜，每支股票每个交易日一次）。每次触发：

- 以 75% 的概率引起关注；
- 强度服从均值为 1 的对数正态（σ = 0.75），上热榜再乘以 0.5（不如首播和快讯显眼）；
- 按半衰期衰减，半衰期在 1–6 小时之间按对数均匀抽取。

关注度 a 让散户的买卖倾向 x 再加 0.25 × a：强度为 1 时散户的买入比例约 62%。

**反应不足与过度反应**（Barberis–Shleifer–Vishny；De Bondt–Thaler）。估值修正（单日对数变化 ≥ 5%，包括快讯带来的修正）是消息型 NPC 的“超预期”。同一支股票同方向、间隔不超过 8 天的修正连成一串，第 k 条的反应倍数：

- k = 1：0.3–0.8 之间均匀抽取（一次超预期被打折）；
- k ≥ 2：1 + (k − 1) × 步长，步长在 0.2–0.6 之间抽取，最多 2.5（连续超预期被放大）；
- 反应的半衰期在 1–8 小时之间按对数均匀抽取（原来固定 2 小时）。

所有随机抽取都是（种子、密钥、股票、时间）的哈希。修正和关注事件写入事件日志，重启时读回，连串和关注不会因重启丢失。

### 6.2 参数的依据

| 参数 | 值 | 依据 |
|---|---|---|
| `sentiment_half_life_days` | 14 | Baker–Wurgler 的情绪指数逐月高度持续；一个赛季 13 周，14 天的半衰期给出几周尺度的冷热交替 |
| `sentiment_strength` | 0.15 | 情绪高 1 个标准差时，普通股票的散户买入比例从 50% 到 57%、金额多 16%：看得出的倾斜，但不压过其他因素 |
| `sentiment_sens` | 0.5–2 | Baker–Wurgler：情绪对小盘、新上市、难估值的股票影响最大；冷门股的敏感度是热门股的 4 倍 |
| `sentiment_band` | ±0.67 | 标准正态的四分位点 |
| `attention` | 0.25 | Barber–Odean：散户在高关注日明显净买入。取强度为 1 时买入比例约 62%（买卖不平衡约四分之一），是“明显但不压倒”的量级；具体数值没有逐表对照论文 |
| `attention_prob`、`attention_sigma`、`attention_half_life_h` | 0.75、0.75、1–6 小时 | 原则 3：是否发生、强弱、持续多久都随机；关注是当天的现象 |
| `attention_rank_n`、`attention_rank_weight` | 6、0.5 | 市场页涨幅、跌幅榜各显示 6 支；榜单不如首播、快讯显眼 |
| `reaction_first`、`reaction_step`、`reaction_max` | 0.3–0.8、0.2–0.6、2.5 | BSV：单次超预期反应不足，连续同向超预期反应过度；具体幅度随机 |
| `reaction_half_life_h` | 1–8 小时 | 围绕原来固定的 2 小时随机 |
| `reaction_window_days` | 8 | 每周一集：相邻两集的快讯连成一串（也是事件保留的天数） |

参数一次定下，没有为了指标回调。仿真中途改过一处：敏感度原来没有缩放到平均为 1，冷门股占多数，使“强度”实际大于上表的含义；改成平均为 1 是让实现符合参数的定义。

### 6.3 验收结果

标准输入（`inputs33`，2026-07-08 至 11-03，119 个交易日）和世界库，种子 1、7、20261105，全部机器人。“关闭”与“开启”是同一个程序，只差 §6 的四个开关。

**机器人**（相对买入持有的超额，3 个种子平均，扣交易成本，单位：百分点；等权 / 市值加权）：

| 机器人 | 关闭 | 开启 |
|---|---|---|
| fade_flash（利空快讯后买入，一天后卖出） | −57.6 / −65.4 | −65.9 / −72.1 |
| ride_flash（利好快讯后买入，一天后卖出） | −24.6 / −32.5 | −30.7 / −37.0 |
| momentum_k（持有过去 5 天涨得最多的 5 支） | −30.9 / −38.8 | −27.6 / −33.9 |
| momentum_1（持有前一天涨得最多的 5 支） | −82.7 / −90.5 | −77.6 / −83.9 |
| contrarian_k（持有过去 5 天跌得最多的 5 支） | −19.0 / −26.8 | −25.2 / −31.5 |
| contrarian_1（持有前一天跌得最多的 5 支） | −51.7 / −59.6 | −46.8 / −53.0 |
| sentiment_timer（火热时清仓，冷淡时买回） | +4.1 / −3.8 | −2.4 / −8.7 |
| premiere_rush（首播前一晚买入，首播后一晚卖出） | −6.8 / −14.6 | −10.3 / −16.6 |
| hold_hottest | +6.4 / −1.5 | +4.2 / −2.1 |

新机器人全部不超过 5 个百分点。原有机器人中，超过等权基准 5 个百分点的在关闭时已有 spoof_scare（+5.9）、bad_price（+9.1）、hold_hottest（+6.4），开启后分别为 +3.0、+0.1、+4.2，都低于市值加权基准；fan_0.1、fan_long_0.3 是有预知能力的对照，开启前后都远超基准。资金检验：三个种子不变量全部成立，NPC 相对被动持有的超额在 5.8%–6.6%（关闭时 6.0%–7.0%）。

**市场特征**（全部股票，3 个种子平均；括号内是冷门三分之一）：

| 特征 | 指标 | 关闭 | 开启 |
|---|---|---|---|
| 波动聚集 | 日收益绝对值自相关，滞后 1 / 2 天 | 0.067 / −0.010（冷门 0.066） | 0.078 / −0.009（冷门 0.111） |
| 波动聚集 | 5 分钟收益绝对值自相关，滞后 1 / 12 | 0.145 / 0.120 | 0.148 / 0.124 |
| 肥尾 | 日收益峰度 | 17.2 | 17.4 |
| 短期反转 | 1 分钟 / 1 小时 / 1 天收益滞后 1 自相关 | −0.032 / −0.043 / −0.050 | −0.031 / −0.044 / −0.059 |
| 中期动量 | 价格/估值偏离的半衰期（天） | 16.3（冷门 22.9） | 19.0（冷门 27.6） |
| 偏离有界 | log(价格/估值) 的 5%、50%、95% 分位 | 0.002 / 0.045 / 0.092 | 0.005 / 0.047 / 0.107 |
| 偏离有界 | 冷门股 95% 分位；同向偏离 10% 以上最长天数的 p90 | 0.108；6 天 | 0.187；23 天 |
| 量与关注 | 日成交笔数与热度的相关（全部 / 去掉个股均值） | 0.66 / 0.50 | 0.71 / 0.55 |
| 情绪 | 火热日与冷淡日平均 log(价格/估值) 之差（冷门） | — | +0.012（+0.023） |

结论：情绪层让冷门股的波动聚集更明显、价格与热度更同步、火热时价格高于价值且冷门股更多，短期反转略增强，肥尾不变，没有一个简单策略能稳定获利。

**没有完全达标的一项：冷门股的偏离持续。** 种子 7 的情绪在赛季后 40 天一直高于 +1.3（最后 +2.7），冷门股价格/估值的 95% 分位到 +26%，同向偏离 10% 以上最长 31 天，冷门组偏离半衰期 40 天（关闭时 25 天）。这是 Baker–Wurgler 机制加上不能卖空的结果：高估只能靠持股的价值型 NPC 卖出和制作委员会在 1.3 倍处减持来压回，冷门股的价值型 NPC 少。三个标准种子的赛季情绪都偏正（这个窗口里，8 个种子有 6 个偏正，种子之间不相关，是抽样巧合）；情绪偏负的种子 6 上，冷门股 95% 分位 0.110、最长 5 天，与关闭时一样。这一项留待卖空（路线图第一阶段）上线后复查；在那之前，如需更严的界限，应缩小 `sentiment_sens` 的上限，而不是降低强度。

**检验的局限：**

- 新机器人大多亏得很多，主要是成本：每天换仓，价差和冲击在一个赛季里累积。它们说明“记住规则就能赚”不成立，但不代表机制完全不可预测。
- 机器人只在 09:00–23:00 交易，看不到深夜的快讯，要到早上才行动。
- 情绪择时只测了反向（火热清仓、冷淡买入），顺势版本没有单独测。
