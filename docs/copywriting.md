# 界面文案规范

## 1. 总则

在表意清楚、读得顺、意思不变的前提下，越短越好。正式、中性、平实；不写废话，不口语，不用黑话。

**能用版面说明的，不写文字。** 不加多余的副标题、说明和标签：位置、分组、对齐和数字格式本身就在表达含义。例如价格旁不写「价格」，涨跌幅用颜色和正负号表达，不再写「涨幅」。

## 2. 用词

- 用常见、具体的词，不用书面化、文学化或含糊的说法。
- 不用网络用语、语气词（哦、啦、呢、哈）和表情符号。
- 同一事物只用一个名称，全站一致，见 §9。
- 操作的名称与它打开的页面标题一致。例如「新股认购」入口打开的页面标题也是「新股认购」。
- 不描述手势或鼠标操作（同时有手机和电脑用户）：写「查看详情」，不写「点击查看详情」。

## 3. 人称与语气

- 能省略人称时省略：「已撤单」，而不是「你已撤单」。
- 必须称呼用户时用「你」，不用「您」。
- 不以「我们」自称；直接说明结果：「无法加载」，而不是「我们加载出了问题」。
- 语气平和，不命令、不责备。少用「请」；不用「请勿」「禁止」「不要」，改为说明怎样做：「用户名只能包含文字、字母和数字」。
- 不用绝对化表达：「绝不」「永远」「最」。
- 不用感叹号。

## 4. 句式

- 重要信息放在句首。
- 一句只讲一件事；需要讲两件事时拆成两句。
- 用主动句，少用「被」字句。
- 同一区域内句式和语序保持一致。
- 不重复用户已知的信息，不描述显而易见的细节。

## 5. 各类文案

| 类型 | 规则 | 示例 |
|---|---|---|
| 标题 | 名词或名词短语，2–8 字，不加标点 | 持仓、新股认购 |
| 按钮 | 动词或动宾短语，2–4 字；写明具体动作，不用笼统的「确定」 | 买入、卖出、撤单、认购 |
| 输入提示 | 说明要填什么或给出示例，不加句号 | 搜索作品或代码 |
| 空状态 | 说明现状，并给出下一步操作 | 「暂无持仓」+ 按钮「去看行情」 |
| 错误 | 说明原因和解决办法，显示在出错位置附近；用「无法」，不用「失败」 | 「可用资金不足」；「无法连接服务器，检查网络后重试」+「重试」 |
| 确认对话框 | 标题用问句写明后果；确认按钮重复具体动作 | 「撤销全部委托？」+「全部撤单」「取消」 |
| 成功提示 | 说明结果，不加感叹号 | 已提交委托 |
| 风险提示 | 陈述事实和可选的做法，不渲染后果 | 市价单按对手方价格成交，成交价可能偏离现价 |

## 6. 标点与格式

- 用全角中文标点；引号用 “”，作品名用《》。
- 单独出现的标题、按钮、标签、输入提示、列表项不加句末标点。由多句组成的说明照常使用标点。
- 省略号用「…」（一个字符）。
- 中文与英文、数字之间加一个半角空格：「第 5 集」「3 笔成交」。数字与「%」之间不加空格。
- 数字一律用阿拉伯数字。
- 时间：「刚刚」「N 秒前」「N 分钟前」（同一小时内）；「今天 HH:mm」；当年为「MM-dd HH:mm」；更早为「yyyy-MM-dd HH:mm」。行情里的成交时间一律用「HH:mm:ss」。
- 大数：
  - 1 万以下显示原数，1 万及以上为「1.2万」，1 亿及以上为「1.2亿」，「万」「亿」与数字之间不加空格。
  - 价格、持仓数量、委托数量、账户金额等需要精确的地方显示完整数字，千分位用逗号。
- 金额单位「币」只在第一次出现或可能混淆时写出；表格和行情里不写。
- 涨跌：上涨为红色并带「+」，下跌为绿色并带「−」（U+2212），平盘为文字色。百分比保留 2 位小数。
- 颜色一色一义：红绿只表示涨跌方向和买卖方向（买入红、卖出绿）。错误提示用琥珀色（`--danger`），选中状态和焦点用文字色，链接、播出标记等非方向的强调用蓝色（`--accent`），品牌红只用于标志。见 `web/src/styles/tokens.css`。
- 实时状态：页头显示「实时」（推送已连接且在交易时段）、「休市」或「连接中断」。自己的委托成交时提示「买入成交 100 股 · 3.21」：方向 + 成交 + 数量 + 股 · 成交均价。

## 7. 个性

基调正式，语气随场景调整。个性文案只用于合适的位置。

**不使用个性文案**：按钮、确认对话框；账号、交易、资金、风险相关的文案；用户需要自行处理的错误。

**可以使用个性文案**：输入框提示、空状态、成功提示、原因不明且用户无法处理的错误、关于页、彩蛋。

保留一条个性文案，应同时满足：去掉个性部分后意思完整；不在高频场景出现；大多数用户能看懂；不会引起争议；同一位置只用一处。有意保留的个性文案列入附录。

## 8. 无障碍

- 图标按钮的无障碍标签写动作，不写图形：「返回」，而不是「左箭头」。
- 图片的描述写内容，不以「图片」开头：封面图写作品名。

## 9. 术语表

|---|---|
| 登录 | 登陆 |
| 账号 | 帐号 |
| 其他 | 其它 |

| 委托 | 订单、挂单（「挂单」只用于描述未成交的限价委托这一状态时） |
| 撤单 | 取消订单 |

| 可用资金 | 可用余额、可用现金 |
