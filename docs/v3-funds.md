# 指数基金（场外）

第三阶段第二项（docs/roadmap.md）。给不想挑股票的玩家一个一键分散的选择：申购一只基金，基金用这笔钱按指数买入全部成分股。原则沿用 docs/game-design.md 开头的三条（1 尽量真实，2 易上手有深度，3 好玩）和路线图总则（信号可靠、不留可以机械套利的规律、回答经济需要）。**待定**表示数值是建议的默认值，还没有定。⚠️ 表示相对现实的简化。

---

## 1. 已定事项（2026-11-08）

| 事项 | 决定 |
|---|---|
| 形式 | 场外开放式基金：向基金申购、赎回，按净值成交，不在交易所挂牌（不是 ETF） |
| 资产 | 基金真的持有成分股，在市场上用申购的钱买入、赎回时卖出。不做由系统当对手方的合成基金：盈亏会凭空产生，破坏 NPC 财富总和不变的设计（docs/v2-npc-market.md §6） |
| 以后 | ETF（场内交易、做市商围绕实时净值报价、实物申赎）和玩家基金在同一套底层上再做，等场外版本稳定之后 |

## 2. 经济需要（路线图总则 4）

| 需要 | 怎么满足 |
|---|---|
| 分散 | 门禁里多数主动策略跑不赢买入持有，但手动等比例买一百多支股票不现实 |
| 降低门槛 | 看好“这一季整体”或“长篇”，不用逐支挑选 |
| 资金回收 | 管理费是一项稳定的资金流出，和融资利息、融券费用一样 |

## 3. 产品

### 3.1 首批

跟踪现有的三个全收益指数（`GET /api/v1/market/indices`，docs/api-v1.md §4.1.4），编制方法不变：

| 基金 | 跟踪 | 成分变化 | 首批上线 |
|---|---|---|---|
| 安易综合指数基金 | `all` 番剧综合指数 | 新股上市、退市 | 是 |
| 安易长篇指数基金 | `long` 长篇连载 | 很少 | 是 |
| 安易本季新番指数基金 | `season` 本季新番 | 换季时几乎全部换掉 | **待定**：换季调仓量大、时间可预测（§6.2），门禁通过后再上 |

主题基金（题材、制作公司）放第二批：先确认标签数据的来源和稳定性。

### 3.2 市值加权的好处

三个指数都按市值加权。股价涨跌时，基金持仓的比例自动跟着变，**不需要调仓**。只有这几种情况要买卖：

| 情况 | 基金的动作 |
|---|---|
| 净申购 / 净赎回 | 按当前权重买入 / 卖出一篮子股票 |
| 新股纳入（上市第二天起计入指数） | 买入新股，同时按比例卖出其他成分 |
| 退市 | 不用卖：退市时返还的现金直接进入基金（指数也按返还的现金计） |
| 配股 | 按指数的复权方式认购或放弃（**待定**：认购需要现金，简单起见先放弃，配股权的价值计入跟踪误差） |
| 拆股、分红 | 不用买卖；分红留在基金里，按权重再投资 |

## 4. 申购和赎回

### 4.1 时间和价格

| 项 | 规则 | 现实依据 |
|---|---|---|
| 提交 | 任何时间，按金额申购、按份额赎回 | 场外基金 |
| 截止 | 交易日结束（04:00）前提交的，算当天的申请 | A 股基金 15:00 截止 |
| 执行 | 下一个开盘集合竞价（08:45–09:00）：基金把当天的净申购或净赎回折成一篮子限价委托，挂进集合竞价 | |
| 确认价 | 集合竞价结束后算出的净值。**提交时不知道成交价** | 未知价原则：2003 年美国基金丑闻（盘后交易、择时套利）之后，各国都要求按提交后的下一个净值成交 |
| 到账 | 申购：开盘后份额到账；赎回：开盘后资金到账 | ⚠️ 现实中 T+1 到 T+3 |

集合竞价没有成交的部分，留作现金，在当天连续交易时段分批买入（每 30 分钟一次，**待定**）。现金部分会带来跟踪误差。

### 4.2 交易成本由申赎的人承担

基金买卖成分股要付佣金和印花税。如果摊到净值里，老份额持有人会为新进出的人买单。所以：

- 申购：实际成交的佣金从申购金额里扣，剩下的按确认净值折成份额。
- 赎回：卖出的佣金和印花税从赎回款里扣。
- 申购和赎回在同一天相互抵消的部分不用买卖，也就没有成本。

现实中叫作反稀释机制（swing pricing / 反稀释费）。

### 4.3 费用

| 费用 | 数值 | 去向 | 现实依据 |
|---|---|---|---|
| 管理费 | 每年 0.5%，按日从净值中计提（**待定**） | 流出经济 | 国内指数基金每年 0.15%–0.5% |
| 申购费 | 无 | | 指数基金的 C 类份额 |
| 短期赎回费 | 持有不满 7 天的份额 1.5%（**待定**） | 计入基金资产，留给其他持有人 | 证监会《开放式证券投资基金销售费用管理规定》：持有少于 7 日的赎回费不低于 1.5% 并全额计入基金财产 |

持有天数按每笔申购分别计算，赎回时先进先出。

### 4.4 限额

| 项 | 规则 | 现实依据 |
|---|---|---|
| 单笔申购 | 不少于 100 星辉 | |
| 巨额赎回 | 一天的净赎回超过基金份额的 10% 时，超出部分按比例延到下一个交易日（**待定**） | 公募基金的巨额赎回条款 |
| 基金规模 | 单支成分股的持仓不超过该股流通股的 20%；达到时暂停申购（**待定**，看回放里的冲击） | 防止基金本身推动股价 |

## 5. 基金账户

- 每只基金是一个特殊账户（类似现有的 `world`），通过同一个引擎下单，持有股票和现金。
- 净值 = （持股市值 + 现金 − 应付管理费）÷ 总份额。持股市值用最新价，每天日结后写入一行历史。
- 持仓、规模、每日净值全部公开（现实中季度披露；这里每天公开，方便玩家理解，也让跟踪误差可以检验）。当天的申赎量不公开，第二天随净值一起公布。
- 玩家的基金份额计入总资产（份额 × 最新净值），也计入排行榜。
- 基金份额暂时不能作融资融券的担保物（**待定**）。

## 6. 门禁（路线图总则 3）

新增的漏洞和要写的机器人。按老规则：3 个种子，顺序跑，相对买入持有的超额不超过 5 个百分点。

### 6.1 机器人

| 机器人 | 策略 | 预期 |
|---|---|---|
| `fund_hold` | 第一天申购综合指数基金，一直持有 | 约等于 `buy_hold_cap` 减管理费；用来量跟踪误差 |
| `fund_timing` | 盘中看到指数大涨就申购、大跌就赎回 | 不赚钱：按下一个开盘的净值成交 |
| `ipo_front_run` | 新股上市第一天买入，第二天在集合竞价卖给基金 | 不超过阈值；超过就改成分几天纳入 |
| `fund_dividend` | 分红前申购、分红后赎回，借基金的长期持有规避分红税 | 被 7 天赎回费抵消 |
| `fund_vs_stocks` | 基金和成分股之间做差价 | 不赚钱：净值本身就是成分股的价格 |
| `season_front_run` | 换季前买入下一季的新番，等基金调仓接盘 | 只在上线本季基金前测 |

### 6.2 换季

本季基金在换季时几乎全部换仓，而且时间可以预测，是最大的抢跑风险。候选办法（门禁时比较）：

1. 新一季的成分在开播后两周内分 10 个交易日逐步纳入。
2. 换季当天不调，旧成分到季末自然退出，新成分按上市顺序逐只纳入。

### 6.3 市场指标

- NPC 财富漂移（docs/v2-npc-market.md §6）。
- 基金执行当天开盘集合竞价的价格偏离：基金的委托是否明显推高或压低开盘价。
- 跟踪误差：基金净值的日收益率与指数日收益率之差的标准差，目标每年 1% 以内（**待定**）。

## 7. 和其他功能的关系

| 功能 | 关系 |
|---|---|
| API 交易 | 申购、赎回用 `trader()`，交易密钥可以操作。按未知价成交，程序没有速度优势 |
| 新股认购 | 基金不参与新股认购，避免和玩家抢份额 |
| 热度期货 | 不冲突：期货按热度结算，基金持有股票 |
| 隐藏估值 | 基金只用价格，不接触估值 |

## 8. 文件和接口（草案）

| 表 | 字段 |
|---|---|
| `funds` | `id, key, name, index_key, account_id, status, fee_rate, created_at` |
| `fund_units` | `account_id, fund_id, lot_id, units, bought_day, cost`：每笔申购一个批次，赎回时先进先出 |
| `fund_requests` | `id, account_id, fund_id, kind, amount_or_units, day, status, nav, units, cash, fee, created_at, settled_at` |

| 接口 | 用途 |
|---|---|
| `GET /api/v1/funds` | 基金列表：净值、规模、近期收益、跟踪误差 |
| `GET /api/v1/funds/{key}` | 详情：持仓、净值走势 |
| `POST /api/v1/me/fund-requests` | 申购 `{fund, amount}` / 赎回 `{fund, units}` |
| `DELETE /api/v1/me/fund-requests/{id}` | 执行前撤回 |
| `GET /api/v1/me/funds` | 我的份额、成本、持有天数 |

## 9. 实施顺序

1. 回放里先做：基金账户、集合竞价执行、净值，加 `fund_hold`、`ipo_front_run` 两个机器人，量跟踪误差和新股纳入的冲击。
2. 门禁跑完 §6.1 的其余机器人。
3. 后端和接口，前端（基金列表、详情、申购赎回、我的基金）。
4. 先上综合指数基金和长篇指数基金；本季基金在换季方案通过门禁后再上。
