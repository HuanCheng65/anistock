# v2 第 2 步：多主体 NPC 市场

目标：只有一个玩家时，市场也像真的一样——有成交、有分歧、有波动、对消息有反应；长期又围绕基本面运行，不被玩家轻易薅羊毛。

本步发布为 v0.3.0。规则写进 `docs/game-design.md`（注明现实依据，简化处标 ⚠️），参数全部放在 `server/game.toml` 的 `[market]` 段。

---

## 1. 为什么现在的市场不动

v1 的 NPC 只有三种：每支股票一个做市商（只挂单，不主动成交）、制作委员会（价格高于估值 1.3 倍才卖）、全市场 6 个随机散户。估值每天 06:30 才变一次，盘中所有 NPC 看的是同一个数，彼此没有分歧——没有分歧就没有成交。

真实市场的成交来自**参与者看法不同、看法随信息变化**。所以本步的核心是：很多个看法不同的 NPC，看法在盘中会漂移、会被事件冲击。

## 2. NPC 类型

学术上这一类模型叫“异质主体模型”（Chiarella–Iori 2002 的限价单簿版本、Lux–Marchesi 1999），能复现真实市场的典型特征：收益分布肥尾、波动聚集、短期价格不可预测。

| 类型 | 行为 | 现实依据 |
|---|---|---|
| **价值型** | 各自有一个“心中的估值” = 隐藏估值 × 个人偏差（偏差长期存在、缓慢漂移）。价格低于心中估值就买，高于就卖，偏离越大下单越多 | 基本面投资者；分析师之间的分歧 |
| **趋势型** | 看最近一段时间（几分钟到几小时，各人不同）的涨跌，追涨杀跌；仓位有上限 | 技术派、动量交易 |
| **消息型** | 平时不动；事件发生时（开播、完结、热度快讯、以后的新闻）按事件方向和强度交易，几小时内逐渐收手 | 事件驱动交易 |
| **散户型** | 小额、随机，偏好热门股，晚上比白天活跃 | 散户噪声交易 |
| **做市商**（保留并改进） | 双边报价；库存越偏离目标报价越偏；**最近波动越大价差越宽**；不再持有全部流通股 | 做市商的库存与风险管理（Avellaneda–Stoikov） |
| **制作委员会**（保留） | 价格高于估值 1.3 倍时减持 | 大股东减持 |

每个 NPC（做市商、委员会除外）有：
- 一个**关注列表**：5–15 支股票，按热度加权抽取。热门股关注的人多，流动性就好——和现实一致。
- 有限的**资金和持仓**，用完就做不了；不能卖空（卖空留到之后的版本）。
- 一个**活跃度**：下次行动的时间按指数分布随机抽取（泊松到达），所以 NPC 的动作天然分散在时间上，不会挤在同一时刻（压测里 p99 偏高的主要原因就是集中触发）。

规模初定：约 600 个 NPC（价值型 40%、趋势型 20%、消息型 10%、散户型 30%），最终数量由仿真校准决定。

## 3. 活跃度

每支股票的 NPC 活跃程度 = 基础值 × 热度^α × 日内曲线 × 事件放大。

- **热度**：用每日输入里的预期热度，热门股成交多、冷门股成交少。
- **日内曲线**：08:45–09:00 集合竞价；白天较平；午休小高峰；20:00–23:00 晚高峰（社团成员主要在晚上活跃，也和多数番剧播出时间一致）。
- **事件放大**：事件发生后活跃度临时放大，几小时内衰减回来。

预算：正常时全市场每秒几笔到十几笔 NPC 委托，事件高峰十倍以内。压测里 2 核在每秒 3000 笔以上仍然正常，余量很大。

## 4. 心中估值如何在盘中变化

隐藏估值每天 06:30 由日结更新一次（不变）。每个价值型 NPC 心中的估值 = 隐藏估值 × exp(个人偏差 + 事件冲击)：

- **个人偏差**：每人每股一个，随时间缓慢随机漂移（均值回归，半衰期几天）。保证任何时刻都有人觉得贵、有人觉得便宜。
- **事件冲击**：事件让所有 NPC 的估值同向移动一段，幅度按事件强度和可信度决定。
  - “基本面类”事件（例：以后的“宣布续作”）冲击会一直保留，直到下一次日结的隐藏估值把它“吸收”或“否定”。
  - “情绪类”事件（例：热度快讯、炎上）冲击按半衰期衰减。
- **偏差和冲击不存数据库**：由（种子，NPC，股票，日期）确定性地生成，重启后完全一样，不需要新表。事件冲击从事件记录重算。

## 5. 事件

统一的事件结构，本步只接内部事件，新闻以后接到同一个入口：

```
Event { company_id, kind, direction(-1/0/1), magnitude(0-10), credibility(official/media/rumor),
        source, ts, sentiment_or_fundamental, half_life }
```

本步的内部事件（都来自已有数据）：
1. **播出时间**：每集播出前 1 小时到播出后 2 小时，该股活跃度上升（粉丝“播出前布局”）。
2. **热度快讯**：每小时抓一次**当天有新集播出**的番在 Bangumi 上的单集吐槽数（每部一个请求），和同一部番前几集同一时间点的吐槽数比较，明显高于平常就是“神回”利好、明显低于就是利空。生成一条游戏内快讯，所有玩家同时看到。
3. **开播、完结、退市预警**：日结里本来就有的消息，同时作为事件。

所有事件在游戏内公告的那一刻起才生效，玩家和 NPC 同时看到。

## 6. 防薅羊毛（验收标准，不是附加项）

仓库是公开的，估值公式和数据源也是公开的，高手完全可以自己算出隐藏估值——这本来就是“基本面分析”，是给高手的深度。所以必须保证 NPC 不是提款机：

| 被测策略 | 要求 |
|---|---|
| 反复吃做市商的价差（低买高卖） | 扣除手续费后不赚钱 |
| 低于估值买入长期持有 | 可以赚，但不应明显超过“买入全市场持有” |
| 拉抬股价引诱趋势型跟风再出货 | 平均不赚钱（VCM 冷静期 + 价值型反向交易 + 委员会减持共同限制） |
| 挂单撤单影响做市商报价 | 做市商不看玩家挂单，只看成交和自己的库存；没有效果 |
| 推到 VCM 冷静期再反向操作 | 不赚钱 |

标准：一个赛季（约 13 周）回放里，以上任何简单程序策略的收益不超过“买入全市场持有”加若干个百分点（具体阈值在仿真后定）。达不到就继续调，设计不算完成。

**NPC 的财富不能漂移**：NPC 是玩家所有交易的对手方。整体上 NPC 一个赛季的盈亏应接近 0。NPC 资金用完时，从“外部世界”账户获得缓慢、有上限的资金流入（每周不超过一定比例），资金过多时流出——相当于基金的申购赎回，账本依旧总和为 0。

## 7. 校准：在 Rust 里用真实引擎做仿真

不另写仿真器，直接用 Rust 引擎（内存模式、不写数据库、时钟加速）回放本季真实的每日输入文件，同一个种子结果完全可复现。几分钟跑完一个赛季。

指标与目标：

| 指标 | 目标 |
|---|---|
| 每支股票成交间隔 | 正常时几分钟一笔，热门股更快 |
| 日内波动（日收益标准差） | 2%–5%；大事件日明显放大 |
| 收益分布 | 肥尾（峰度 > 3） |
| 波动聚集 | 收益绝对值的自相关为正，缓慢衰减 |
| 短期可预测性 | 1 分钟、1 小时收益的自相关 ≈ 0 |
| 价格回归估值 | 价格/估值 的偏离半衰期为几天 |
| 买卖价差 | 热门股约 0.5%–1%，冷门股更宽 |
| NPC 整体盈亏 | 赛季内接近 0 |
| 第 6 节的被测策略 | 全部达标 |

仿真输出一份报告（图表 + 指标表），作为 v0.3.0 的验收材料。

**标准输入集。** 回放必须用和模型同一版本的每日输入。v0.3.2 起估值需要输入里的 `prior`（开播前一天冻结的“当时可知”预估）、`observed`、`sources`；用旧格式的输入回放，每部番的滤波都只能从第一批数据起步，估值会滞后于公开热度，“买最热的三支持有”之类的策略就会虚高（实测：旧输入下 hold_hottest +114% 对买入持有 +39%；标准输入下低于按市值买入持有）。所以 `marketsim` 遇到缺这些字段的输入会直接报错（`--allow-old-inputs` 才放行，只用于对比），服务器每次日结也会警告。

## 8. 上线时的持仓迁移

现在每支股票的流通股基本都在做市商手里。v0.3.0 启动时做一次性迁移（数据库迁移 002，先自动备份）：

- 做市商保留目标库存（例如流通股的 20%），其余按当前价格转给价值型和散户型 NPC，NPC 用从外部世界账户获得的资金付款；做市商多出的现金退回外部世界账户。
- 全部走账本，记录原因 `npc_rebalance`，总和为 0；玩家的持仓和资金不受任何影响。

## 11. 流动性（v0.3.4）

玩家反馈：价差大、挂单很久不成交。原因是做市商太薄：每档几百币，一笔一万币的单子就能吃穿整个盘口。

**做市商改成"指定做市商"（交易所的 DMM 制度）：**

- 报价围绕市场价，不再围绕隐藏估值（`mm_anchor_to_price = 1`）。做市商不知道估值，把价格拉回估值是价值型 NPC 的事。价值型 NPC 因此增加到 3 倍（`n_value`）。
- 版权方把 20% 的股份借给做市商（`mm_loan_frac`），相当于发行人把股票借给指定做市商，保证报价背后有库存。场外按最新价划转，钱由外部世界账户出，不成交、不动价格。库存卖完后借券继续报卖价，见 §12。
- 最小报价量：每档至少 1,500 币（`mm_quote_min`），共 5 档，档距为半个价差的一半。
- 库存管理只调整报价数量（`mm_size_skew`），不调整报价价格。以最新价为锚时调价格会自我强化：做市商压低报价，下一笔成交也就压低了最新价。
- 遇到信息事件时报价放宽、数量减小（`mm_event_widen`）：开播前 1 小时到热度快讯后 2 小时、事件发布后 2 小时、开盘后半小时。逆向成交（上次报价后的成交到这次已经亏钱）也会放宽报价（`mm_toxicity_mult`）。

**自适应流动性：玩家活跃时 NPC 让位，玩家不在时 NPC 补位（`adapt_*`）。** 代码已经写好，但默认关闭，v0.3.4 不启用：两个被测策略的结果在不同种子之间相差很大，暂时无法判断它是否过关。

按股票分别计量玩家的活跃度，取两部分之和：

- 玩家的成交额，30 分钟半衰期的指数平均；
- 玩家在中间价 ±2% 内挂了 5 分钟以上的单子。

只挂不成交、马上撤单的单子不算，所以刷单撤单造不出活跃度。

做市商"补位，不抢位"：

- 只补足目标深度减去玩家深度的部分，每边至少保留四分之一。
- 玩家的最优价离做市商自己的报价不远时，做市商不抢到它前面，而是排在它后面。离得远的坏价格不理会，所以挂坏价格拉不动做市商。

散户型和趋势型 NPC 的活跃度按股票缩放：玩家越活跃越少，最低 ×0.5，最高 ×2。价值型 NPC 不变，它们是锚。

**上线（已有数据库）：** 启动时先备份，再做以下三件事：

- 按配置补足 NPC 人数。新的价值型 NPC 只有现金、没有持仓，人数记在 `npc_population_extra`。
  - 现金只给配置的三分之一（`grow_cash_scale`）。在仿真里，一次补足全额现金会让整体价格水平在头两周高出约 3%；给三分之一时只高 1–1.5%。分两周逐步补足没有明显改善。
- 版权方借股给做市商，每支股票的完成情况记在 `mm_loan:<id>`。
- 做市商现金补到 `mm_cash`，已补到的水平记在 `npc_mm_cash`。

三件事都可以重复执行，重复不会再动。玩家的资金和持仓不受影响。

仿真工具：`marketsim --probe`（`--probe-players N`）加入 N 个普通玩家，测量以下几项：

- 价差
- 限价单成交等待时间
- 1k/10k/50k 币的冲击
- 5 人各 5 万币同时买入一支股票后价格偏离多久
- 做市商在每类对手方身上的输赢
- 做市商和玩家在同一价位的排队先后

另有两个被测策略：`spoof_scare` 挂大单把 NPC 吓退，`bad_price` 挂坏价格等 NPC 来成交。

## 12. 做市商借券卖出（2026-11-06 热修复）

**事故。** 11 月 5 日，20 部番第一次接上 Annict（日本市场）数据。《侦探已经死了。第二季》（100010）的日本营收从 0 变成每天约 638 币，隐藏估值从约 4.0 重估到 9.07。价值型 NPC 一路买入，做市商的库存降到 2 股。价格到了估值附近以后，37 个 NPC 持有人（4,498 股）不在估值附近卖，制作委员会（5,500 股）要到估值的 1.3 倍才减持，盘口只剩做市商的一张 2 股卖单和很深的买单。估值没有错，缺的是流动性设计：做市商库存为 0 时就不再报卖价。

**改为：库存卖完后，做市商借券继续报卖价。** 指定做市商有持续双边报价的义务，库存不够时借券履行：科创板做市商可以通过转融通借入证券，港交所的指定做市商（designated specialist）同样要持续报价，美国 Reg SHO 对真实做市（bona fide market making）也有专门安排。规则：

- 做市商的持仓 = 持股 − 欠券，可以为负。库存降到 0 后，卖单改为**融券卖出**：从和玩家同一个券源（制作委员会，`lend_frac`、`stock_cap`）借券，走同一套信用委托（价格不低于最新价、融券费、分红补偿、维持担保比例、强平），账本照样总和为 0。见 `docs/v2-margin.md` §8。
- **上限**：欠券不超过总股数的 `mm_loan_frac`（20%），也就是版权方承诺给做市商的那个数，不另设参数。实际上先碰到的是券源上限（所有借券人共用流通部分的 25%：100010 现在是 1,125 股）、保证金（每支股票的做市商账户约 5 万币现金，融券保证金比例 100%）和下面的数量倾斜。
- **库存倾斜穿过 0 继续**：`mm_size_skew` 的公式不变，只是不再在库存为 0 处截断。持仓越负，卖单越小、买单越大；`mm_inventory_skew = 0`，所以不调价格，只调数量。卖单在持仓约为 −0.43 × 目标库存时缩到 0（目标 2,500 股时约 −1,070 股），中间没有台阶。
- **价格回落时先还券**：欠券期间做市商的每张买单都是买券还券，合计不超过欠券；还清之后才重新用普通买单持股。
- 报价中心、价差和其他做市参数都不变。
- 只在连续交易时段、对融资融券标的（上市满 5 天、不是低价股、没有退市警示）借券。新股上市头 5 天用认购份额和版权方配给的库存报价。
- **不豁免集中度上限**：每支股票一个做市商账户，账户里只有这一支股票，“单支股票的融资融券不超过净资产”和 100% 的融券保证金限制的是同一个量，豁免没有意义。做市商也和玩家一样会被追保、被强平。

**库存为 0 的那一次报价**：先挂买单（普通买入），再挂融券卖单，因为欠券以后不能再普通买入。如果先挂的买单在欠券期间成交，做市商会短暂地同时持股和欠券；下一次报价先卖出持股、用买券还券还券，持股卖完前不再新增融券。这是做市商唯一和玩家不同的地方（玩家不能同时做多做空同一支股票），理由是双边报价义务。库存还剩几股时（事故里的 2 股）只挂这几股，卖掉后下一次报价（平均 3 分钟）开始借券。

**版权方配给（`mm_loan_frac`）保留，不用借券取代。** 两者都由版权方供股，但借券覆盖不了配给：

- 新股上市时委员会持有 7,500 股、流通部分 2,500 股，券源上限只有 625 股，而配给是 2,000 股；
- 做市商的目标库存（流通部分的 20% + 配给，即 500 + 2,000 = 2,500 股）同时决定数量倾斜和买单上限（目标 × `mm_inventory_cap` = 7,500 股）。去掉配给后目标变成 500 股，买单上限 1,500 股，已经持有配给股的做市商（例如还持有 2,500 股的）会停止报买价，直到卖掉 1,000 股以上。

配给本身不是借贷：当时由外部世界账户按最新价付给委员会，股票归做市商，没有欠款，所以不需要迁移，`mm_loan:<id>` 照旧记录已配给的数量。两者用同一个 20%：配给是做市商多头一侧的库存，借券是空头一侧的上限。

## 13. 热门股的流动性：做市商的波动率估计（2026-11-06）

**问题。** `spoof_scare`（每 30 分钟在最热的 3 支股票中间价 ±1.5% 挂买卖单，成交就留着）每季稳定赚到资本的 9%–15% 的价差，对手主要是散户和趋势型 NPC。现实里最热门的股票价差最窄：做市的人多，互相压价，离中间价 1.5% 的挂单只有在价格真的移动时才会成交，成交后通常继续亏（逆向选择）。

**原因。** 新的诊断（`marketsim` 的 `metrics.json` → `hot_liquidity`：最热 3 支股票每 5 分钟采样一次盘口）显示，平时（非信息窗口）做市商的半价差中位数 1.43%，其中波动项 1.41%、基础项只有 0.3%；做市商 78% 的时间不在最优价，中间价 ±1.5% 内的挂单只有约 7,300 币。也就是说，挂在 ±1.5% 的单子就在做市商报价的第一、二档之间，是盘口上的正常报价，自然稳定赚价差。

波动项来自做市商对最新成交价变化的估计。逐笔成交的价格在买价和卖价之间来回跳（bid-ask bounce）：最热的几支股票逐笔收益率的一阶自相关是 −0.2 到 −0.3，5 分钟收益率标准差 1.4%–1.8%（如果是真实波动，相当于日波动 9% 以上，实际日波动约 5%）。做市商把自己报价造成的来回跳当成了波动，于是加宽报价，报价越宽跳得越大，形成自我强化。信息窗口（开播前后等）不是原因：最热的 3 支股票只有约 4% 的采样落在信息窗口里。

**修正（`mm_vol_roll = true`）。** 做市商用 Roll（1984）的方法去掉买卖价来回跳：成交价变化的方差加上两倍的相邻变化协方差，才是有效价格的方差（来回跳让方差多出 2s²、让相邻协方差少 s²）。这是现实中估计波动率的标准做法：用中间价或扣除微观结构噪声，而不是直接用成交价。没有新参数；做市商仍然只看成交价，不看盘口（挂单撤单影响不了它）。

**结果**（标准输入、世界库、热度快讯，种子 1、7、20261105；“之前”是合并第一阶段后的 main）：

| | 之前 | 修正后 |
|---|---|---|
| 最热 3 支：做市商半价差中位数 | 1.43% | 0.45% |
| 最热 3 支：中间价 ±1.5% 内的挂单 | 约 7,300 币 | 约 78,000 币 |
| 热门三分之一的价差中位数 / p90 | 0.9% / 2.3% | 0.6% / 1.4%（§7 的目标 0.5%–1%） |
| `spoof_scare` 相对按市值买入持有 | +16.6（+0.4..+36.4） | −3.0（−21.5..+16.4） |
| `bad_price` / `scalper` | +2.6 / −23.8 | −2.6 / −17.4 |

代价：做市商报价窄而深之后，承接了更多价值型 NPC 的成交，做市商的交易损益（相对持有初始库存）从每季约 −1 万到 +5 万币变为 −39 万到 −58 万币，NPC 投资者相对被动持有的超额从约 5% 升到约 9%；热门股价格对估值偏离的半衰期从约 4 天变为约 7 天，全部股票从约 12 天变为约 20 天（第一阶段之前的 main 约 16–27 天）。做市商亏钱是指定做市商承担的成本，现实中由交易所的返佣和做市补贴弥补；这里没有为了这个结果再调参数。

## 14. 做市商随估值修正调整报价（2026-11-07）

§11 让做市商报价围绕市场价、不知道估值。估值修正（快讯、每小时的更新、日结）后，做市商仍按旧的最新价报价，夜盘里 NPC 又少，价格要几个小时才跟上：修好快讯的观测噪声（`docs/v2-valuation.md` §3.4）之后，快讯一出就买、30 分钟后卖的机器人相对买入持有高出 9 个百分点（夜盘回放，1 个种子）。

现实的做市商看到公开消息会立即改报价，否则会被知情交易者吃掉（Glosten–Milgrom 的逆向选择）。所以（`mm_follow_revisions = true`）：

- 估值每修正一次，做市商的参考价按修正的比例同步移动（参考价 = 最新价 × exp(上次成交以来的累计修正)），并在这一秒重新报价，在任何人下单之前完成。
- 下一笔成交之后，修正已经体现在最新价里，累计值清零。
- 做市商依然不知道估值的水平，只跟随变化量。价格相对估值的偏离（情绪、泡沫）照样保留，价值型 NPC 的作用不变。玩家从报价跳动里能看出这次修正大概多大，看不出估值本身。
- 休市时的修正（日结）让做市商的下一次报价（集合竞价）带上它。

结果（完整门禁，夜盘回放，3 个种子，`docs/v2-api-access.md` §7.1）：快讯狙击相对买入持有平均 −11.0 / −8.2 个百分点（只修估值、不跟随时种子 1 为 +9.1）。依靠价格滞后的机器人普遍变差：`contrarian_k` +36.9 → −10.2，`momentum_k` +9.1 → −27.1，`scalper` −6.4 → −30.9（种子 1 的旧门禁 → 新门禁平均，旧门禁没有夜盘，只作方向参考）。市场指标：价差中位数 0.70%–0.71%，日波动中位数 5.5%–5.6%，价格/估值偏离的半衰期 6.0 / 9.9 / 11.5 天（旧门禁种子 1 为 7.2 天）。

代价：价值型 NPC 一直立刻知道估值的变化，原来能吃到做市商的旧报价（知情交易的利润），现在做市商抢先调价。NPC 交易者的交易损益为 −22.1% / −22.6% / −20.1%（旧门禁种子 1 为 −16.7%），做市商 −4.7% / −9.4% / −9.5%（旧 −13.8%）。NPC 财富漂移 +11.2% / +5.0% / +9.9%（旧 +15.7%），仍为正，§6 的要求满足。半衰期在种子 2、3 偏长，合并 `prior-fix` 后重跑时再看是否需要调整价值型 NPC 的强度。
