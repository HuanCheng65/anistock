# 长期规划

更新：2026-11-06。按顺序推进，哪条先做完先发哪条。

## 总则

1. **信号可靠。** 进入估值或结算的数据，必须来自已有的可靠外部输入，或我们能准确获取的数据。拿不稳的数据源不用，比如 Oricon 销量是付费数据，免费页面拿不到，所以不用。
2. **符合真实规律，同时好玩。** 平台本身是虚构的。要求的是机制像真实市场，各类参与者（玩家、NPC、做市商、公司管理层）按自己的激励和约束行动，结果符合常识。底层是扎实的金融学和经济学原理，并在真实与趣味之间取平衡。
3. **不留可以机械套利的规律。** 每个新机制都配检验机器人，3 个种子平均下来，相对买入持有的超额不超过 5 个百分点。种子只改变市场里的噪声；选股不受种子影响、只建一次仓的机器人（比如第一天买入最热的 3 支一直持有），3 个种子是同一个组合的三次重复，不是三次独立的检验，它的结果只作参考。这类策略改为定期重新选股（`hold_hottest_28` 每 28 天换成当时最热的 3 支），按上面的标准判定。选股类策略（只建一次仓的和定期重选的）的超额超过 5 个百分点时，再看快速检验（`sim/quickcheck.py`）按股票拆开的结果：去掉贡献最大的一两支后不超过 5 个百分点，并且这一两支各自有作品本身的原因（写进文档：是哪几支、为什么），记为个股表现；去掉之后仍然超过，不通过。

   2026-11-07 的例子：`hold_hottest` 3 个种子平均 +12.9，三个种子买的都是同样三支；`hold_hottest_28` −9.5。快速检验“最热三支，持有 28 天”平均每笔 +19.7（区间 −4 到 +45），其中《学生会也有洞！》4 笔平均 +125%、《无职转生 第三季》11 笔平均 +24%，去掉这两支其余 21 笔平均 −2.5%。前者是开播后热度远超预期（估值从 23 涨到 61，其中一部分是季初份额的问题，docs/design/valuation.md §3.14），后者是整季热度几乎不衰减（同上 §3.10）。
4. **每个产品都要回答它解决什么经济需要**：融资、对冲、汇总信息、稳定收入、降低门槛，至少占一个。

## 第一阶段：模型地基（v0.6.0 上线；绝对营收和续作期权已实现，12 月初数据够了再打开）

依据 `sim/calibration/long_tail_sequel.md`（采集中）：

- **一个系列一支股票。** 新一季是同一家公司的事件。少数热度互不相关的分支，按“子公司独立上市”处理，用手动表维护。现有按季上市的股票，通过换股合并迁移过来。
- **长尾收入。** 完结后热度落到一个非零的底（初测：美国市场约为播出期的 10%，几年内几乎不再下降）。中国市场的长尾改用收藏类指标，单集吐槽只代表播出期的讨论。
- **续作期权。** 按人气、评分、原作类型估计续作的概率和间隔（初测：3 年内约 30%，人气前 10% 的作品约 54%）。
- **绝对营收。** 营收 = 自身热度 × 各市场的变现率，用平台的长期规模归一化：有大年小年，但不随平台增长而漂移。
- **折现率**与资产寿命一起重新确定。
- **生命周期**：退市条件，以及续作上市的处理方式。
- **交易品种抽象**：撮合、账本、行情从“股票”泛化为“交易品种”，每种品种有自己的结算规则，为后续新产品铺路。

## 第二阶段：把股票做完整（v0.6.0 上线；处置效应已实现，暂不打开，见 docs/design/sentiment.md §7.3）

新产品都建立在一个完整的股票市场之上，所以先把股票本身做完。

| 顺序 | 内容 | 说明 |
|---|---|---|
| 1 | 情绪层第一批 | 见 docs/design/sentiment.md |
| 2 | 新闻事件 + 公司资本政策 | 续作公布、延期、炎上通过新闻插件进入估值；管理层按公开的资本政策行事：拆股（股价超过门槛）、配股为续作融资（优序融资理论、Myers–Majluf）、回购（自由现金流理论、信号理论） |
| 3 | 融资融券 | 杠杆买入和卖空；保证金、强制平仓、融券费率；穿仓由破产重整兜底 |
| 4 | 情绪层第二批 | 追涨泡沫、处置效应（有了卖空，泡沫才有对手盘） |

## 第三阶段：新的金融产品

| 顺序 | 内容 | 说明 |
|---|---|---|
| 1 | 热度期货 / 预测合约 | 按热度、评分等数据结算，玩家之间零和 |

## 不做

| 内容 | 原因 |
|---|---|
| Oricon 销量作为固定数据源 | 付费数据，覆盖面窄 |
| 系统生成的传闻 | 违背信号可靠原则；真实传闻由新闻插件提供 |
| 虚拟货币（常驻） | 不对应番剧经济的需要，会抽走核心玩法的资金，观感上也有风险 |
| 外汇 | 复杂度远大于乐趣 |

## 运营

- 指数（v0.6.0 已上线）：成分按当日在市的股票计算，保留退市股票退市前的涨跌（消除幸存者偏差）；增加全收益口径（除息日加回每股分红），作为主指数；拆股、配股用复权价，与 K 线前复权一致

- QQ 机器人：功能和交互由用户设计，接口见 docs/api-v1.md
- 冬季番上线准备：12 月初开始。用积累的开播前快照校准先验，并演练换季
- 公开前（v1.0）：开放注册、去掉邀请码、核查商标、整体打磨
