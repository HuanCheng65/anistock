# 长期规划

更新：2026-11-06。按顺序推进，哪条先做完先发哪条。

## 总则

1. **信号可靠。** 进入估值或结算的数据，必须来自已有的可靠外部输入，或我们能准确获取的数据。拿不稳的数据源不用，比如 Oricon 销量是付费数据，免费页面拿不到，所以不用。
2. **符合真实规律，同时好玩。** 平台本身是虚构的。要求的是机制像真实市场，各类参与者（玩家、NPC、做市商、公司管理层）按自己的激励和约束行动，结果符合常识。底层是扎实的金融学和经济学原理，并在真实与趣味之间取平衡。
3. **不留可以机械套利的规律。** 每个新机制都配检验机器人，3 个种子平均下来，相对买入持有的超额不超过 5 个百分点。
4. **每个产品都要回答它解决什么经济需要**：融资、对冲、汇总信息、稳定收入、降低门槛，至少占一个。

## 地基：模型重新设计（进行中）

依据 `sim/calibration/long_tail_sequel.md`（采集中）：

- **一个系列一支股票。** 新一季是同一家公司的事件。少数热度互不相关的分支，按“子公司独立上市”处理，用手动表维护。现有按季上市的股票，通过换股合并迁移过来。
- **长尾收入。** 完结后热度落到一个非零的底（初测：美国市场约为播出期的 10%，几年内几乎不再下降）。中国市场的长尾改用收藏类指标，单集吐槽只代表播出期的讨论。
- **续作期权。** 按人气、评分、原作类型估计续作的概率和间隔（初测：3 年内约 30%，人气前 10% 的作品约 54%）。
- **绝对营收。** 营收 = 自身热度 × 各市场的变现率，用平台的长期规模归一化：有大年小年，但不随平台增长而漂移。
- **折现率**与资产寿命一起重新确定。
- **生命周期**：退市条件，以及续作上市的处理方式。
- **交易品种抽象**：撮合、账本、行情从“股票”泛化为“交易品种”，每种品种有自己的结算规则，为后续新产品铺路。

## 上层

| 顺序 | 内容 | 说明 |
|---|---|---|
| 1 | 情绪层第一批 | 见 docs/v2-sentiment.md |
| 2 | 新闻事件 + 公司资本政策 | 续作公布、延期、炎上通过新闻插件进入估值；管理层按公开的资本政策行事：拆股（股价超过门槛）、配股或发债为续作融资（优序融资理论、Myers–Majluf）、回购（自由现金流理论、信号理论） |
| 3 | 热度期货 / 预测合约 | 按热度、评分等数据结算，玩家之间零和 |
| 4 | LLM 收盘播报 + QQ 机器人 | LLM 只做理解和表达，事实全部来自数据 |
| 5 | 指数基金和主题基金 | 当季、长篇，以及类型、制作公司等主题 |
| 6 | 债券 | 国债（利率风险，配合央行议息）；制作债（信用风险，可能违约） |
| 7 | 融资融券 | 保证金、强制平仓；穿仓由破产重整兜底 |
| 8 | 分析师 NPC、玩家基金、赛季赛 | 分析师观点由有偏差的模型生成，历史准确率公开 |

## 不做

| 内容 | 原因 |
|---|---|
| Oricon 销量作为固定数据源 | 付费数据，覆盖面窄 |
| 系统生成的传闻 | 违背信号可靠原则；真实传闻由新闻插件提供 |
| 虚拟货币（常驻） | 不对应番剧经济的需要，会抽走核心玩法的资金，观感上也有风险 |
| 外汇 | 复杂度远大于乐趣 |
